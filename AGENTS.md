# Ophel Atlas Documentation Instructions

## About this project

- Documentation site built on [Mintlify](https://mintlify.com) (`docs.json`, root English `.mdx`, Chinese `zh/*.mdx`).
- `landing/` contains the Astro marketing site for `ophel.app`; `worker/` routes `/docs` and landing traffic on Cloudflare.
- `changelog.mdx` and `zh/changelog.mdx` are generated by `node scripts/sync-changelog.mjs` from the main `ophel` repo — do not edit them manually.
- Verify docs edits with `mint validate` and `mint broken-links --check-anchors`.
- Verify landing edits with `pnpm --dir landing typecheck`, `pnpm --dir landing format:check`, and `pnpm --dir landing build`.

## Terminology

Keep product terms aligned with the actual UI labels in `ophel/src/locales/{en,zh-CN}/index.ts`:

- **Site Packs** (EN) / **适配中心** & **站点适配包** (ZH) — avoid mixing "Site Extensions" in user-facing copy (keep existing `/enhancements/site-extensions/*` file paths for URL stability).
- **Chats** (EN) / **对话** (ZH) — except inside Global Search syntax (`type:conversations`).
- **Global Search** (EN) / **全局搜索** (ZH) — never use legacy "Search Everywhere".
- **Zen Mode** / **Clean Mode** (EN) / **禅模式** / **净化模式** (ZH).
- **Qianwen** (EN) / **通义千问（Qianwen）** (ZH); **Qwen Studio** (`chat.qwen.ai`); **Doubao / Dola** (`doubao.com` / `dola.com`); **Gemini Notebook** (`notebook.google.com`).
- Sound preset labels: **Default**, **Soft Chime**, **Glass Ping**, **Bright Alert** (never expose internal keys like `softChime`).
- Always cite real settings paths: **General**, **Appearance**, **Features**, **Site Settings**, **Site Packs**, **Keyboard Shortcuts**, **Data & Permissions**, **About** (ZH: 基本设置、外观主题、功能模块、站点设置、适配中心、快捷键位、数据与权限、关于).

## Style preferences

- Verify every default value, shortcut, permission, capability, and setting path against `ophel` source code before documenting it.
- Write directly in plain language for users — avoid internal architecture jargon, marketing adjectives, and translationese.
- Keep English and Chinese pages structurally mirrored; every internal link in `zh/*.mdx` must start with `/zh/`.
- Use active voice, second person ("you"), sentence case headings, bold for UI elements, and code formatting for commands, paths, filenames, and CSS variables.
- Do not embed JSX components (such as `<Icon />`) inside Markdown headings (`##` / `###`), and do not leave unused imports.
- For Ophel keyboard shortcuts, use `/snippets/shortcut.jsx` instead of hand-writing Mac variants. `ctrl` maps to Windows/Linux `Ctrl` and Mac `Command`; `alt` maps to Windows/Linux `Alt` and Mac `Option`. Prompt submit is the only documented exception: `Ctrl+Enter` remains `Ctrl+Enter` on Mac (`sameOnMac`).
- For MP4 videos referenced in MDX, use `/snippets/docs-video.jsx` so `/docs` subpath deployments resolve the asset path cleanly.
