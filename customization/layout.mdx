All page layout controls live under **Settings → Site Settings → Page Layout** and are stored independently per site (falling back to defaults if you have not customized a site).

## Smart Avoidance (Beta)

**Smart Avoidance** (default **On**, supported on all 16 built-in sites) automatically reserves horizontal space so the open Floating panel sits beside the conversation instead of covering text or tables.

  src="/images/panel/panel-aware-layout.mp4"
  label="Smart Avoidance resizing the chat area cleanly when the Ophel Floating panel opens"
/>

- Only activates when the desktop panel is expanded in **Floating** mode.
- Hovering the collapsed droplet to peek at the panel, using **Edge Snap**, or triggering temporary **Widen on hover** never activates Smart Avoidance, preventing page jitter.

## Page width and user message width

Most AI sites lock replies inside a narrow central column even on wide monitors. Under **Settings → Site Settings → Page Layout** (supported on 15 built-in sites, all except Gemini Notebook):

| Setting | Range | Default | What it adjusts |
| --- | --- | --- | --- |
| **Page Width** | `40%`–`99%` | Off (`81%` when enabled) | Widens the main conversation column so wide code blocks and tables fit without awkward wrapping. |
| **User Query Width** | `40%`–`99%` | Off (`81%` when enabled) | Controls the width of your own message bubbles independently. |

## Zen Mode

**Zen Mode** (default **Off**, supported on 15 built-in sites, all except Gemini Notebook) hides the site's native sidebars, top bars, and surrounding chrome so you can focus purely on the conversation. Zen Mode also includes Clean Mode effects.

- **Temporary toggle**: Press <Shortcut combo="ctrl+shift+z" /> or click the eye icon in the floating quick buttons.
- **Persistent per site**: Turn on **Zen Mode** under **Settings → Site Settings → Page Layout**.
- **Show Exit Button** (default **On**): Displays a floating exit button while Zen Mode is active; turn it off if you prefer exiting exclusively with <Shortcut combo="ctrl+shift+z" />.

## Clean Mode

**Clean Mode** (default **On**, supported on 14 built-in sites—all except Gemini Notebook and Grok) quietly removes low-value distractions such as AI disclaimer banners, upgrade nags, and promotional cards without altering the core chat layout.

## Auto-hide input (Gemini, Beta)

Available on **Gemini** (default **Off**): slides the bottom prompt input out of view while you read long replies. Move your cursor to the bottom of the screen, insert a prompt from Ophel, or press <Shortcut combo="alt+i" /> to bring the input box right back.

## Panel size and docking behavior

Controls for the Ophel panel itself—Floating vs. Edge Snap mode, width (`240–600 px`), temporary hover width (`520 px`), height (`50–100 vh`), snap threshold, and margins—live under **Settings → General → Panel**. See [Panel Overview — Panel size and position settings](/panel-overview#panel-size-and-position-settings).
