Ophel includes **46 customizable keyboard shortcuts** organized into 6 categories, plus quick gestures and a browser-wide Global URL command.

<ShortcutLegend lang="en" />

## Viewing and editing shortcuts

- Press <Shortcut combo="alt+backslash" /> on any supported page to jump straight to the shortcut list.
- Open **Settings → Keyboard Shortcuts** to toggle **Enable Custom Shortcuts** (default **On**), click any binding to record a new key combination, click `×` to unbind an action, or click **Reset to Defaults**.
- Ophel automatically detects conflicting bindings and normalizes physical key codes so macOS `Option` combinations work reliably without typing special characters.

## Prompt send key

The **Keyboard Shortcuts** page also displays your current **Send Message** key with a direct link to **Settings → Features → Prompts**:

- Default: **`Enter`** to send, `Shift+Enter` for a new line.
- Optional: **<Shortcut combo="ctrl+enter" sameOnMac />** to send, `Enter` for a new line. **On macOS, this remains `Ctrl+Enter` (not `⌘+Enter`).**

## Special non-rebindable gestures

| Gesture | Action |
| --- | --- |
| Hold <Shortcut combo="ctrl" /> alone for `0.2 s` | **Pass-through click (Ghost mode)**: temporarily click straight through the Ophel panel and floating buttons to reach the page underneath. |
| Double-press `Shift` (within `360 ms`) | Opens **Global Search** anywhere in a supported AI tab (off by default; enable in **Settings → Features → Global Search**). |

## Global URL browser command (Extension only)

Browser extension builds register a browser-wide command (`open-global-url`, suggested key <Shortcut combo="alt+o" />) that opens your favorite AI platform from **any** browser tab—even non-AI sites:

- Set the target URL under **Settings → Keyboard Shortcuts → Global URL** (default: `https://gemini.google.com`).
- Change the key combination in your browser's extension shortcut manager:
  - **Chrome**: `chrome://extensions/shortcuts` (direct button in Ophel Settings).
  - **Edge**: `edge://extensions/shortcuts` (direct button in Ophel Settings).
  - **Firefox**: Open `about:addons` → gear icon → **Manage Extension Shortcuts**.
- Userscript builds do not support browser-wide commands (all 46 in-page shortcuts work identically).
