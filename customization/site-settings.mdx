Open **Settings → Site Settings** and pick any built-in platform or installed Site Pack from the site selector at the top (your active site is pinned first; selecting another site shows a reminder banner).

Everything for the selected site appears on one page in four sections:

1. **Page Layout** — Smart Avoidance, page/prompt widths, Zen Mode, Clean Mode, and auto-hide input (see [Layout](/customization/layout)).
2. **Model Lock** — Automatically switch to your preferred model when opening a site.
3. **Hide Ophel on specific pages** — Hide the UI on selected URL paths.
4. **Site-specific settings** — Dedicated options for **Gemini**, **AI Studio**, **ChatGPT**, and **Claude**.

## Model Lock

Model Lock automatically selects your preferred model whenever a chat page loads, while still letting you switch models manually mid-conversation.

- **How matching works**: Enter a case-insensitive keyword (for example `pro`, `o3`, `sonnet`) and Ophel picks the first matching model in the site's selector. On **AI Studio**, Ophel reads and caches the model dropdown list so you can pick from a dropdown directly.
- **Quick toggle**: Turn Model Lock on or off for the current site from **Toolbox → Model Lock**, or jump to this card with <Shortcut combo="ctrl+alt+l" />.
- **Supported built-in sites (14 of 16)**: ChatGPT, Gemini, Gemini Enterprise, AI Studio, Claude, Grok, Doubao / Dola, Kimi, Qwen Studio, Qianwen, Yuanbao, ChatGLM, ima, and Z.ai. *(Not available on **DeepSeek** or **Gemini Notebook**.)*

## Hide Ophel on specific pages

Hide the Ophel panel and floating quick buttons on specific paths of a site (for example, embedded previews or share pages) while keeping background modules running:

- **Wildcard rules** (default): `*` matches any characters along `location.pathname` (for example `/artifact/*`).
- **Regex rules**: Toggle `.*` to match with a regular expression (for example `^/(artifact|share)/`).
- Click **Use current page** to prefill the path of the tab you are currently viewing.

## Disable Ophel on a site entirely

To stop Ophel from initializing on a built-in platform altogether, use any of three places:

- Click the power/disable button at the top-right of **Settings → Site Settings** when viewing that site.
- Toggle it off under **Settings → Site Packs → Built-in sites**.
- Toggle it off in the browser toolbar popup.

## Gemini settings

Available when **Gemini** is selected (shortcut: <Shortcut combo="ctrl+alt+g" />):

| Setting | Default | What it does |
| --- | --- | --- |
| **Markdown Bold Fix** | Off | Fixes unrendered `**bold**` Markdown sequences that sometimes appear in Gemini replies. |
| **Remove Image Watermark** | Off | Removes the visible star watermark on **Gemini AI-generated images** across page display, download, copy, and Markdown/ZIP export. |

<Note>
**Watermark removal permissions & platform support**: On Chrome, Edge, and Firefox extensions, enabling Gemini watermark removal requests the optional `<all_urls>` permission so Ophel can fetch and process watermarked images cleanly. Userscript builds work without an extra prompt. Not supported in experimental macOS Safari.
</Note>

- **Automatic MyStuff / Library enhancement**: On Gemini's `/mystuff` and `/library` pages, Ophel automatically adds an **Open in new tab** action to media cards and resolves document items straight to their original conversations—no toggle needed.

## AI Studio settings

Available when **AI Studio** is selected (default model selection lives in the **Model Lock** card on the same page):

| Setting | Default | What it does |
| --- | --- | --- |
| **Collapse Sidebar** | Off | Collapses the left navigation bar on load *(extension preload only)*. |
| **Collapse Run Settings Panel** | Off | Collapses the right-hand Run Settings panel on load *(extension preload only)*. |
| **Collapse Tools Section** | Off | Collapses the Tools subsection inside Run Settings *(extension preload only)*. |
| **Collapse Advanced Settings** | Off | Collapses the Advanced Settings subsection *(extension preload only)*. |
| **Enable Search Tool by Default** | **On** | Keeps Google Search grounding enabled by default *(extension preload only)*. |
| **Remove Watermark** | Off *(Extension)* | Blocks AI Studio's `watermark_v4.png` page background watermark (requires page refresh; *extension preload only*). |
| **Markdown Bold Fix** | Off (Extension) / On (Userscript) | Fixes unrendered `**bold**` text in responses (works on both extension and userscript). |

<Note>
Except for **Markdown Bold Fix**, the AI Studio options above rely on the extension's `document_start` preload script and do not apply to userscript builds.
</Note>

## ChatGPT settings

Available when **ChatGPT** is selected:

| Setting | Default | What it does |
| --- | --- | --- |
| **Markdown Bold Fix** | Off | Fixes unrendered `**bold**` sequences in replies. |
| **Load Code Blocks in Batches** | **On** | Mounts CodeMirror blocks in batches so opening or switching long coding chats feels smoother. |
| **Reduce Animations While Generating** | **On** | Pauses heavy message-area animations while streaming to cut CPU/GPU usage. |
| **Disable Backdrop Blur** | Off | Turns off frosted-glass `backdrop-filter` effects to reduce frame drops when scrolling long threads. |

## Claude settings (Session Key switcher)

Available when **Claude** is selected (shortcut: <Shortcut combo="ctrl+alt+c" />). Lets you store multiple Claude Session Keys (`sk-ant-sidXX-...`) and switch accounts without signing out manually:

- **Add keys**: Enter a key manually, import/export a JSON list (merges without duplicates), or click **Import from browser** (extension builds only; requests the optional `cookies` permission to read your active `sessionKey` cookie).
- **Test keys**: Click **Test** on a single key or **Test all** (tests sequentially every **500 ms** to check validity and account tier).
- **Switch safely**: Switch to any saved key—or press <Shortcut combo="ctrl+alt+s" /> to rotate to the next valid key. On extension builds, Ophel checks whether another Claude tab is currently generating before switching so you do not interrupt an active reply.
- **Userscript notes**: Userscript builds support manual/JSON keys, testing, and switching while on `claude.ai`, but do not support **Import from browser** or cross-tab generating checks.
- **Organization isolation**: Synced Claude chats are isolated automatically per account and organization.

Looking for **Advanced Model Usage Estimate** (daily send counter and token chart)? It lives under **Settings → Features → Alerts** — see [Tabs, Alerts & Usage Estimate](/enhancements/tab-notifications#advanced-model-usage-estimate).
</Tip>
