Different AI platforms have different page structures, behaviors, and account models. Ophel lets you configure settings independently for each site rather than applying a single global configuration. Go to **Settings → Site Settings**: **Page Layout** and **Model Lock** apply to the site you are currently on, while the **Gemini**, **AI Studio**, **ChatGPT**, and **Claude** tabs hold each platform's own options.

## Model lock

Model lock solves a common annoyance: manually switching back to your preferred model every time you open an AI platform. Once configured, Ophel checks the model selector after the page loads and switches to your target model automatically. If the target model isn't available on your account, Ophel leaves the current selection untouched.

**To set up model lock:**

1. Open the target AI platform, then go to **Settings → Site Settings → Model Lock**
2. Toggle it on
3. Enter a keyword from the target model's name (matching is case-insensitive)

<Note>
  The **Model Lock** tab only appears on sites that support it; on unsupported
  sites (such as DeepSeek) it is not shown.
</Note>

<Tip>
  You only need part of the model name. Entering `flash` matches `Gemini 2.0 Flash`. If multiple models match, the first match is selected.
</Tip>

Each site's model lock setting is independent, so you can configure different target models for different platforms. You can also toggle model lock for the current site quickly from <Icon src="/images/icons/tools.svg" alt="Toolbox icon" /> **Toolbox** → <Icon src="/images/icons/model-lock.svg" alt="Model lock icon" /> **Model Lock**.

<Note>
  If you manually switch to a different model during a session, model lock only kicks in again on the next page load — it won't override your manual selection mid-session.
</Note>

## Markdown rendering fixes

Some AI platforms have intermittent Markdown rendering bugs — bold text failing to render is a common example. Ophel provides site-specific toggles to patch these issues without affecting other platforms.

| Site | Path | Default |
| --- | --- | --- |
| Gemini | Settings → Site Settings → Gemini → Markdown Bold Fix | Off |
| AI Studio | Settings → Site Settings → AI Studio → Markdown Bold Fix | Off |
| ChatGPT | Settings → Site Settings → ChatGPT → Markdown Bold Fix | Off |

The fix is off by default on all three platforms — enable it only when you actually see rendering problems.

## Gemini watermark removal

When you export or screenshot a Gemini chat, Gemini appends a "Created with Gemini" watermark. Ophel can strip this watermark automatically.

**Settings → Site Settings → Gemini → Remove Image Watermark**

<Note>
  Watermark removal requires the `<all_urls>` host permission, which Ophel will ask you to grant the first time you enable this setting. This permission lets Ophel intercept and modify the export request before it reaches the page. The setting is off by default.
</Note>

The same watermark removal option is also available for AI Studio under **Settings → Site Settings → AI Studio → Remove Image Watermark**.

## Gemini Enterprise: policy retry

**Settings → Site Settings → Gemini**, in the Gemini Enterprise section:

| Setting | Description | Default |
| --- | --- | --- |
| Auto-retry on Policy Block | Automatically retry requests blocked by enterprise content policies (for false-positive triggers) | Off |
| Max Retries | Maximum consecutive retries when enabled, 1–10 | 3 |

## AI Studio settings

**Settings → Site Settings → AI Studio** provides controls for the initial state of various sections on the AI Studio page, so you don't have to collapse them manually every time you open it:

| Setting | Description | Default |
| --- | --- | --- |
| Collapse Sidebar by Default | Auto-collapse the left navigation bar when opening the page | Off |
| Collapse Run Settings Panel by Default | Auto-collapse the right run settings panel when opening the page | Off |
| Collapse Tools Section by Default | Auto-collapse the tools section inside run settings | Off |
| Collapse Advanced Settings by Default | Auto-collapse the advanced options inside run settings | Off |
| Enable Search Tool by Default | Auto-enable Google real-time search when opening the page | On |
| Remove Image Watermark | Remove the watermark from AI Studio generated images (takes effect after a page reload) | Off |
| Markdown Bold Fix | Fix intermittent bold text rendering failures | Off |

## Claude session key management

Claude accounts have usage rate limits. When one account hits its cap, you normally have to wait for a reset. If you have multiple Claude accounts, Ophel can store Session Keys for all of them and let you switch instantly — keeping the chat going without logging out and back in.

A Session Key (`sk-ant-sid...` format) is the authentication token your browser session uses on claude.ai. Ophel injects the specified key into requests so you can switch accounts without a full logout cycle. Keys are stored locally in your browser and are never sent to Ophel's servers.

**Adding a session key** — go to **Settings → Site Settings → Claude**:

<Tabs>
  <Tab title="Auto-import (recommended)">
    Click **Import current session**. Ophel reads the Session Key for your currently logged-in Claude account directly from your browser's cookies — no manual copying required.

    <Note>
      Auto-import requires the cookie access permission for claude.ai. Ophel will prompt you to grant it if needed.
    </Note>
  </Tab>
  <Tab title="Manual add">
    Click the Add button and paste a Session Key string in `sk-ant-sid...` format. You can add a label to each key to identify which account it belongs to.
  </Tab>
</Tabs>

**Switching between accounts:**

<Tabs>
  <Tab title="Settings page">
    Go to <Icon src="/images/icons/settings.svg" alt="Settings icon" /> **Settings → Site Settings → Claude** and select a key from the current Session Key selector, or use **Set as current** on a key row.
  </Tab>
  <Tab title="Keyboard shortcut">
    Press <Icon src="/images/icons/keyboard.svg" alt="Keyboard shortcut icon" /> <Shortcut combo="ctrl+alt+s" /> to switch to the next key in your list.
  </Tab>
</Tabs>

After switching, Ophel refreshes the current Claude page to apply the new key.

**Managing the key list:**

| Action | Description |
| --- | --- |
| <Icon src="/images/icons/check.svg" alt="Set current key icon" /> Set as current | Make a specific key the active account |
| <Icon src="/images/icons/shield-check.svg" alt="Test key icon" /> Test single | Send a lightweight request to verify the key is valid and not rate-limited |
| <Icon src="/images/icons/sync.svg" alt="Test all keys icon" /> Test all | Validate all keys in sequence, with 500 ms between tests to avoid triggering rate limits |
| <Icon src="/images/icons/export.svg" alt="Export keys icon" /> Export | Export all keys as a <Icon src="/images/icons/json-file.svg" alt="JSON file icon" /> JSON file for backup |
| <Icon src="/images/icons/import.svg" alt="Import keys icon" /> Import | Restore a key list from a <Icon src="/images/icons/json-file.svg" alt="JSON file icon" /> JSON file |
| <Icon src="/images/icons/delete.svg" alt="Delete key icon" /> Delete | Remove a single entry — does not affect the Claude account itself |

<Warning>
  Exported JSON files contain the full Session Keys. Anyone with the file can use your account's quota. Be careful when sharing WebDAV backups or local files that contain exported keys.
</Warning>

## Usage monitor

For AI services with daily usage limits, Ophel provides a local counter that shows how many chat turns you have used today and roughly how many tokens were consumed.

The usage monitor runs entirely locally — it does not call any external APIs or rely on usage data from the platform. Ophel counts turns and estimates tokens by observing messages on the page.

**Settings → Features → Alerts → Local Usage Counter & Estimate**:

| Setting | Description | Default |
| --- | --- | --- |
| Enable local advanced-model counter and estimate | Show the local counter widget near the input field | Off |
| Estimated daily chat limit | Used for the 80% / 100% threshold reminders; local estimate only | 100 |
| Enable auto reset | Automatically reset the count each day | Off |

When enabled, the widget shows today's send count, input/output character stats, rough token estimates, and progress toward your daily limit.

<Note>
  Token estimates are based on character counting and may differ from the platform's actual billing. Treat them as a rough reference, not an exact measure.
</Note>
