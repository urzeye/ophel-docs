Ophel requests only the baseline permissions needed to run on supported AI sites, and asks for optional permissions only when you enable a feature that requires them.

Manage optional permissions anytime under **Settings → Data & Permissions → Permissions** (extension builds; hidden on userscript builds).

## Required permissions

These permissions are declared in `manifest.json` when you install the extension:

| Permission | Browsers | Purpose |
| --- | --- | --- |
| `storage` *(+ `unlimitedStorage` on Safari)* | All extensions | Saves your settings, folders, tags, prompts, bookmarks, reading history, and installed Site Packs locally. |
| `alarms` | All extensions | Runs background schedules for WebDAV automatic backups and 24-hour Site Pack index checks. |
| `declarativeNetRequestWithHostAccess` | Chrome, Edge, Firefox *(not used on Safari)* | Sets `Referer`, `Origin`, and CORS headers **only for extension background fetches** to `*.googleusercontent.com` and `*.google.com` (explicitly excluding normal page requests) so Gemini image watermark removal and attachment downloads work reliably. |
| `host_permissions` (28 built-in domains & asset CDNs) | All extensions | Lets Ophel mount on the 16 built-in AI platforms and download embedded images/attachments from their official CDNs during ZIP export or watermark removal. |
| `scripting` *(added at build time)* | All extensions | Registers main-world helper scripts and dynamically registers content scripts for Site Packs you install. |

## Optional permissions (requested on demand)

Optional permissions start **off** and are requested only when you trigger the feature that needs them:

| Permission | Requested when | What happens if you revoke it |
| --- | --- | --- |
| `notifications` *(not on Safari)* | Enabling **Desktop Notification** in **Settings → Features → Alerts** | Turns off the completion alert switch automatically (both desktop notifications and completion sounds stop; tab status icons and auto-focus still work). |
| `cookies` | Clicking **Import from browser** or switching accounts in **Settings → Site Settings → Claude** | Ophel can no longer read or update your `claude.ai` `sessionKey` cookie. |
| `<all_urls>` *(host access)* | Enabling **WebDAV Sync** (Chrome/Edge/Firefox) or **Gemini Image Watermark Removal** | Turns off Gemini watermark removal and blocks WebDAV cross-host requests. Installed Site Packs stay installed and fall back to per-origin host prompts. |
| **Per-origin Site Pack host access** | Installing a Site Pack or binding a custom self-hosted URL | Ophel stops injecting on that site until re-authorized. Uninstalling a pack or deleting a binding revokes unused managed origins automatically. |

<Note>
Granting `<all_urls>` also covers installed Site Pack origins and cross-origin attachment fetching during export without requiring separate prompts per origin.
</Note>

## Granting and revoking permissions

- **Chrome / Edge / Firefox**: Open **Settings → Data & Permissions → Permissions** to see live grant status and click **Allow** or **Revoke** on each optional permission. When triggered from an AI page's Settings modal, Ophel opens a small browser permission window so the native browser prompt can appear cleanly.
- **Safari (macOS, Experimental)**: Safari does not allow extensions to toggle website access via `chrome.permissions.request()`. Instead, open **Safari → Settings → Extensions → Ophel Atlas** and allow the AI sites (or WebDAV server host) you want to use.
- **Userscript**: Userscript managers handle host matching through script `@match` / `@connect` headers rather than browser extension permission dialogs, so the **Permissions** tab is hidden.
