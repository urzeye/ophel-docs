Ophel Atlas is built local-first. You do not need an Ophel account, we do not run a cloud backend for your chats, and we never inject ads or behavioral analytics into the extension.

## Where your data lives

Your settings, folders, tags, prompts, prompt chains, bookmarks, reading history, usage estimates, and installed Site Packs stay on your own device:

- **Browser extensions (Chrome / Edge / Firefox / Safari)**: Stored locally via `chrome.storage.local`.
- **Userscript (Tampermonkey / Violentmonkey / ScriptCat)**: Stored locally via your userscript manager's GM storage (`GM_getValue` / `GM_setValue`).

Your actual AI chat messages remain on the AI platform you are using; Ophel only stores lightweight metadata (such as titles, URLs, folder assignments, tags, and pins) locally.

## Complete list of network requests

Ophel makes **zero background telemetry requests**. The only external network requests Ophel can initiate are:

1. **WebDAV sync (off by default)**: Only when you configure and enable WebDAV sync or automatic backups. Requests go directly from your browser to **your own WebDAV server**—never through an Ophel relay.
2. **Site Packs & selector patch index check (on by default, can be disabled)**: When **Auto-update** is enabled under **Settings → Site Packs → Browse & updates**, Ophel sends an anonymous read-only `GET` request once every 24 hours to jsDelivr (`cdn.jsdelivr.net`) or GitHub (`raw.githubusercontent.com`) to fetch the Ed25519-signed index. No cookies, user IDs, or chat data are transmitted.
3. **Optional uninstall survey (Chrome / Edge / Firefox only)**: When you remove the extension, your browser may open `https://ophel.app/uninstall/` with basic non-identifying query parameters (extension version, browser name, UI language, days since install). Filling it in is completely voluntary; if you choose to submit, your selected reason and comment are sent to our PostHog project using a random one-time ID—no account, email, or user identifier is collected.

## Claude Session Keys

If you use Claude multi-account switching, your Session Keys (`sk-ant-sidXX-...`) are saved in your browser's local storage and are included in **Full Backup** JSON exports and all WebDAV backups (both manual and scheduled). Keep exported backup files and your WebDAV storage private.

## Permissions transparency

Ophel follows least-privilege permissions—requesting optional permissions only when you turn on a feature that needs them. See [Permissions](/data/permissions) for a breakdown of every required and optional permission.

Firefox's manifest explicitly declares `data_collection_permissions: { required: ["none"] }`.

## Open source

Ophel Atlas is open source under the **GPLv3** license. You can inspect every line of code, build from source, or report security concerns on [GitHub](https://github.com/urzeye/ophel).
