All Ophel data is stored locally in your browser. Open **Settings → Data & Permissions → Local Backup** to export portable JSON backups or restore data on a new browser or device.

## Export a local backup

Choose one of three export scopes:

| Export type | What is included |
| --- | --- |
| **Full Backup (Recommended)** | Settings, Prompt Library, Prompt Chains, folders, tags, chat metadata (titles, URLs, pins), reading history, Claude Session Keys, bookmarks, usage monitor history, and installed Site Packs with custom site bindings. *(Excludes WebDAV scheduler runtime state and remote registry cache; does not contain AI chat message bodies.)* |
| **Prompts Only** | Prompt Library and Prompt Chains. |
| **Settings Only** | All Ophel preferences and layout/theme configurations. |

<Warning>
If you store Claude Session Keys in Ophel, a **Full Backup** contains those keys in plain JSON. Keep backup files private and never share them publicly.
</Warning>

## Restore from a backup

1. Open **Settings → Data & Permissions → Local Backup**.
2. Drag and drop a backup `.json` file, click to browse, or expand **Paste JSON text** to paste raw backup JSON directly.
3. Review the live summary preview showing what the backup contains, then confirm the restore. Ophel applies the data and reloads affected tabs automatically.

<Note>
**Overwrite vs. merge**: Restoring from **Local Backup** overwrites the categories present in that backup file. If you want to **merge** prompts without erasing existing ones, use the import button directly inside the **Prompts** tab instead. If you want to merge Claude Session Keys, use JSON import inside **Settings → Site Settings → Claude**.
</Note>

- **Reauthorizing Site Packs**: If your backup includes installed Site Packs or custom self-hosted URLs, open **Settings → Site Packs** after restoring and use the **Reauthorize restored site packs** section to re-approve their browser host permissions.

## Clear all data

At the bottom of **Local Backup**, **Clear All Data** permanently deletes all local Ophel settings, folders, tags, prompts, bookmarks, reading history, and keys after a confirmation prompt, returning Ophel to a fresh install state. Your actual chats on AI websites are untouched.
