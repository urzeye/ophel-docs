WebDAV sync lets you back up and restore your Ophel workspace directly between your browser and a WebDAV server you control—with zero Ophel relay servers in between.

## Supported providers

Open **Settings → Data & Permissions → WebDAV Sync** and pick one of **7 presets**:

| Provider | Typical WebDAV URL | Notes |
| --- | --- | --- |
| **Nutstore (Jianguoyun)** | `https://dav.jianguoyun.com/dav/` | Create an app-specific password under Account Security → Third-party app management. |
| **InfiniCLOUD** | `https://connect.infini.cloud/dav` | Enable Apps Connection and use the generated app password. |
| **pCloud** | `https://webdav.pcloud.com` (or `ewebdav.pcloud.com` for EU) | Use your pCloud credentials or app password. |
| **Nextcloud** | `https://your-domain/remote.php/dav/files/username/` | Create an app password under Personal Settings → Security. |
| **Synology NAS** | `https://your-nas-address/webdav/` | Enable WebDAV Server in DSM. |
| **Seafile** | Your Seafile SeafDAV URL | Enable SeafDAV on your server. |
| **Custom** | Any `https://` or `http://` WebDAV URL | Both `https://` and `http://` are supported; always use `https://` over public networks (`http://` is best limited to trusted LAN servers). |

## What gets backed up

- **Manual backups** upload a **Full Backup** (settings, Prompt Library, Prompt Chains, folders, tags, chat metadata, reading history, Claude Session Keys, bookmarks, usage monitor history, and installed Site Packs with custom site bindings).
- **Scheduled automatic backups** upload the same Full Backup **minus reading history** to keep snapshots compact and avoid churn.
- Your actual AI chat transcripts always stay on the AI platforms.
- **Default remote directory**: `ophel` (created automatically on first upload).
- **Safe restore**: Restoring from WebDAV **preserves your local WebDAV connection credentials** so you never overwrite your own sync setup.

## Initial setup and manual backup

<Steps>
  <Step title="Open WebDAV Sync">
    Go to **Settings → Data & Permissions → WebDAV Sync**.
  </Step>
  <Step title="Enter your server details">
    Select a provider preset (or **Custom**), enter the server URL (`https://` recommended; `http://` allowed for LAN servers), username, password / app password, and remote directory (default `ophel`).
  </Step>
  <Step title="Grant host access (extension builds)">
    Click **Test Connection**. Chrome, Edge, and Firefox extensions request the optional host access permission (`<all_urls>`); macOS Safari guides you to allow the specific WebDAV server host in Safari Settings. Userscript builds connect directly via `GM_xmlhttpRequest` with no browser prompt.
  </Step>
  <Step title="Save and back up">
    Save your settings and click **Backup Now** to upload your first snapshot.
  </Step>
</Steps>

## Scheduled automatic backups

Turn on **Automatic Backup** in **Settings → Data & Permissions → WebDAV Sync** to keep snapshots up to date without manual uploads:

- **Interval**: Choose **Every hour (60 min)**, **Every 6 hours (360 min)**, or **Every day (1440 min, default)**. Enabling automatic backups or changing the target server schedules the first run right away.
- **Lightweight snapshots**: Automatic backups exclude reading history.
- **Per-device retention (7 copies)**: Automatic backups are named `ophel_backup_auto_{deviceId}_{timestamp}.json` and automatically keep the **latest 7 automatic backups per device**, so multiple devices never overwrite one another.
- **Manual restore only**: Automatic backups never silently overwrite your local data. If a scheduled run fails (25-second timeout per request), the WebDAV card displays a failed sync status; click **Test Connection** or **Backup Now** to inspect the exact error message.
- **Extension vs. Userscript scheduling**: Chrome, Edge, and Firefox extensions schedule runs in the background via `chrome.alarms`. Userscript builds coordinate across tabs and require at least one supported AI tab to be open for scheduled runs to fire.

## Restoring on another device

1. Configure the same WebDAV server, credentials, and directory on your second device.
2. Click **Restore** to browse the **full list of remote backups** in your directory (both manual and per-device automatic snapshots).
3. Select the snapshot you want to restore and confirm. Your local WebDAV credentials remain untouched.
