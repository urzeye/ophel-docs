这一组功能在 AI 对话页面上叠加额外的交互能力，让读写体验更顺手。

## 用户问题 Markdown 渲染

AI 输入框里写的 Markdown 语法（`**加粗**`、代码块、`- 列表` 等）发送后，消息气泡里通常只显示纯文本。启用此功能后，Ophel 会在你的消息气泡中渲染 Markdown 格式，让问题更便于阅读。

**设置 → 功能模块 → 内容交互 → 用户提问样式优化**（默认开启）

## 双击复制公式源码

AI 回复中包含数学公式时，鼠标双击公式渲染块，Ophel 会把对应源码复制到剪贴板。你可以选择复制 **LaTeX 源码** 或 **MathML 源码**。

**设置 → 功能模块 → 内容交互 → 双击复制公式**（默认开启）

### 公式复制格式

在 **设置 → 功能模块 → 内容交互 → 公式复制格式** 中选择：

- **LaTeX 源码** — 适合 Markdown 笔记、TeX 编辑器、Obsidian、Typora 和再次发给 AI
- **MathML 源码** — 适合无障碍工作流、网页文档和需要保留结构化数学标记的工具

<Note>
  部分站点只暴露视觉渲染后的公式 HTML，没有稳定源码。遇到这种情况时，Ophel
  会提示当前公式缺少可复制源码，而不是复制不可靠的内容。
</Note>

### LaTeX 分隔符

当复制格式为 **LaTeX 源码** 时，可以开启 **设置 → 功能模块 → 内容交互 → 复制时添加分隔符**。开启后：

- 行内公式会复制为 `$ ... $`
- 块级公式会复制为 `$$ ... $$`

如果目标工具需要完整的 Markdown 数学片段，建议开启此选项。

## 一键复制 Markdown 表格

AI 回复中的表格会额外出现一个"复制"按钮。点击后，表格内容以标准 Markdown 表格语法复制到剪贴板，可直接粘贴到支持 Markdown 的编辑器中。

**设置 → 功能模块 → 内容交互 → 表格复制 Markdown**（默认开启）

## Mermaid 图表兜底渲染

部分 AI 平台不会将 AI 回复中的 Mermaid 代码块渲染为图表。Ophel 在这类平台上会尝试自动将 Mermaid 代码渲染为图形。

<Note>此功能只在平台本身未渲染 Mermaid 时生效，不会干扰已有渲染结果。</Note>

**设置 → 功能模块 → 内容交互 → AI 回复 Mermaid 渲染**（默认开启）

## Markdown 修复（Gemini / AI Studio / ChatGPT）

Gemini、AI Studio 和 ChatGPT 在某些情况下存在**加粗文字无法正常渲染**的问题。Ophel 对受影响的平台提供修复补丁：

- **设置 → 站点设置 → Gemini → Markdown 加粗修复**
- **设置 → 站点设置 → AI Studio → Markdown 加粗修复**
- **设置 → 站点设置 → ChatGPT → Markdown 加粗修复**

## 去水印（Gemini / AI Studio）

Gemini 和 AI Studio 在导出/截图某些内容时会附加水印。开启后，Ophel 会在导出时去除这些水印。

<Note>
  此功能依赖可选权限 `<all_urls>`（用于抓取图片并转为 base64）。首次启用时，浏览器会弹出权限请求，确认授权后生效。
</Note>

**设置 → 站点设置 → Gemini → 移除图片水印**

## 导出选项

在当前对话页，可以点击 <Icon src="/images/icons/tools.svg" alt="工具箱图标" /> **工具箱** → <Icon src="/images/icons/export.svg" alt="导出图标" /> **导出**，将对话保存为 <Icon src="/images/icons/markdown.svg" alt="Markdown 文件图标" /> Markdown。对话标签页的行菜单还可以选择 <Icon src="/images/icons/json-file.svg" alt="JSON 文件图标" /> JSON 或 <Icon src="/images/icons/txt-file.svg" alt="TXT 文件图标" /> TXT。

**设置 → 功能模块 → 对话 → 导出设置**：

| 设置项 | 说明 |
| --- | --- |
| 自定义用户名称 | 导出文件中替代"我"的名称，留空则使用默认 |
| 自定义 AI 名称 | 导出文件中替代 AI 名称的文字，留空则使用平台名 |
| 导出文件名包含时间戳 | 导出时为文件名添加时间戳后缀，防止同名覆盖 |
| 导出包含思维链 | 导出时包含支持平台的 AI 推理过程（如 Claude、Kimi、Qwen Studio 等） |
| Markdown 导出方式 | **仅 Markdown** 导出单个 `.md` 文件；**Zip 资源包** 将 Markdown 连同引用的图片和附件打包为 `.zip` |

<Tip>
  Zip 打包的目录结构、各平台资源导出能力以及高级导出功能（Deep Research 报告、Canvas 代码、文档 Artifact）的详细说明，请参阅专门的[导出功能](/features/export)页面。
</Tip>
