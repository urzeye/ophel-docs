Ophel 在对话页面内直接增强排版渲染和复制效率。全局内容交互开关位于 **设置 → 功能模块 → 内容交互**。

## AI 回复 Mermaid 渲染增强

不少平台只会把 Mermaid 图表显示成纯代码块。开启 **AI 回复 Mermaid 渲染增强**（默认 **关闭**）后，在未原生支持 Mermaid 渲染的平台上，Ophel 会自动将 Mermaid 代码块渲染为可交互的 SVG 图表：

- 支持 **50%–300%** 自由缩放。
- 支持全屏查看大图细节。
- 支持导出 **2× 高清 PNG** 图片。

## 渲染用户提问中的 Markdown 和公式

很多平台会把你自己发出的问题显示成一团纯文本。开启 **渲染用户提问中的 Markdown 和公式**（默认 **开启**）后，你发送的标题、列表、数学公式和代码块（带一键复制按钮）都会按标准排版显示。

## 公式双击复制

当 AI 平台渲染出数学公式后，开启 **公式双击复制**（默认 **开启**）即可双击任意公式直接复制源码到剪贴板。

点击内容交互卡片底部的 **高级选项**，还可以调整：

- **公式复制格式**：`LaTeX`（默认）或 `MathML`。
- **复制时保留定界符**（默认 **开启**）：自动为行内公式加上 `$ ... $`，为块级公式加上 `$$ ... $$`。

## 表格一键复制 Markdown

开启 **表格一键复制 Markdown**（默认 **开启**）后，AI 回复中的每个表格右上角都会出现复制按钮，点击即可拿到标准 Markdown 表格源码，方便直接粘贴到笔记软件中。

## 设置项一览

路径：**设置 → 功能模块 → 内容交互**

| 设置项 | 可选项 | 默认值 | 所在位置 |
| --- | --- | --- | --- |
| **AI 回复 Mermaid 渲染增强** | 开启 / 关闭 | 关闭 | 卡片主区 |
| **渲染用户提问中的 Markdown 和公式** | 开启 / 关闭 | 开启 | 卡片主区 |
| **公式双击复制** | 开启 / 关闭 | 开启 | 卡片主区 |
| **表格一键复制 Markdown** | 开启 / 关闭 | 开启 | 卡片主区 |
| **公式复制格式** | LaTeX / MathML | LaTeX | 底部 **高级选项** |
| **复制时保留定界符** | 开启 / 关闭 | 开启 | 底部 **高级选项** |

## 站点专属的内容增强

针对特定平台的修复和优化统一放在 **设置 → 站点设置** 中，而非全局内容交互页：

- **Markdown 加粗修复**（Gemini、AI Studio、ChatGPT）
- **生成图片去水印**（Gemini）与 **背景水印屏蔽**（AI Studio）
- **长对话渲染性能优化**（ChatGPT）

详见[站点设置](/zh/customization/site-settings)；如需导出整场对话或图片附件，见[导出对话](/zh/features/export)。
