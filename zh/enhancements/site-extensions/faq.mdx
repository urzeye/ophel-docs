<AccordionGroup>
  <Accordion title="为什么站点适配包没有「对话」标签页或模型锁定？">
    站点适配包采用安全的纯 JSON 配置，不执行自定义脚本。像历史对话列表同步、多账号隔离和模型锁定这类强依赖平台接口的功能目前只由内置站点适配器提供；适配包专注于大纲、基础导出、提示词插入、宽屏、禅/净化模式和主题同步等通用能力。
  </Accordion>

  <Accordion title="自部署站点支持 HTTP 内网地址（如 http://192.168.1.10:3000）吗？">
    支持。在 **设置 → 适配中心 → 自定义站点** 中绑定自定义地址时，同时支持精确的 `https://` 和 `http://` 站点根地址（协议 + 主机 + 可选端口，不带路径或通配符）。只有社区在线库中默认内置的公开站点规则才要求必须是 `https://`。
  </Accordion>

  <Accordion title="同一个适配包绑定两个不同自建服务器，数据会混在一起吗？">
    不会。Ophel 会按「适配包 + 站点地址」分开存放你的站点设置、书签与阅读记录，公司内网实例和家里自建实例互不干扰。
  </Accordion>

  <Accordion title="站点适配包可以覆盖 16 个内置平台吗？">
    默认不行——只要某个内置站点处于启用状态，Ophel 会阻止冲突的适配包，避免两套规则打架。如果你先在 **设置 → 适配中心 → 内置站点** 里停用了该内置平台，则允许用社区或本地适配包接管同一域名。
  </Accordion>

  <Accordion title="在线适配库的自动更新会上传我的数据吗？可以关闭吗？">
    不会上传任何个人数据。开启自动更新（默认开启）后，Ophel 每 24 小时发起一次匿名只读 GET 请求拉取带数字签名的索引文件。你可以随时在 **设置 → 适配中心 → 获取与更新** 中关闭自动更新，改为按需手动点 **检查更新**。
  </Accordion>

  <Accordion title="网站改版后，某个适配包突然失效怎么办？">
    1. 先到 **设置 → 适配中心 → 获取与更新** 点击 **检查更新**，看看社区是否已经推送了修复版本。
    2. 检查该适配包是否仍处于启用状态且已授予域名访问权限（特别是刚恢复完备份之后）。
    3. 如果仍未恢复，欢迎在 [GitHub Issues](https://github.com/urzeye/ophel/issues) 反馈站点名称和具体失效现象，或者参考[编写适配包](/zh/enhancements/site-extensions/authoring)提交更新。
  </Accordion>

  <Accordion title="「获取与更新」底部的「内置配置补丁」是什么？">
    当某个内置平台突然改动网页结构、但浏览器商店审核还需要 1–3 天时，Ophel 可以通过签名的轻量补丁先热修选择器。默认折叠的「内置配置补丁」区供进阶用户或开发者查看、忽略、回退远程补丁，或导入本地补丁文件测试。
  </Accordion>

  <Accordion title="卸载适配包会清空我在该站点的设置吗？">
    不会。卸载只会移除适配包本体和它的自定义地址绑定，你在该站点保存的布局偏好与本地记录都会保留，以后重装就能接着用。
  </Accordion>
</AccordionGroup>
