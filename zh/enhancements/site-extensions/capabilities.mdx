<Note>
本页是面向 **适配包作者与贡献者** 的技术参考。如果你只是想安装和使用现有适配包，请看[适配中心概览](/zh/enhancements/site-extensions)与[安装与管理](/zh/enhancements/site-extensions/installation)。
</Note>

每个站点适配包通过 `capabilities` 数组声明目标网站支持哪些能力。校验器会强制核对每一项声明的能力是否都配置了必需字段；未声明的能力会在 Ophel 界面中自动隐藏对应控件。

完整源码定义位于 [ophel 仓库](https://github.com/urzeye/ophel)的 `src/adapters/feature-capabilities.ts`、`src/adapters/declarative/validate.ts` 与 `registry/schema/site-pack.schema.json`。

## 15 项能力 ID 一览

| 能力 ID | 对应功能 | 适配包中的必需配置字段 |
| --- | --- | --- |
| `outline` | 多级标题大纲（`H1`–`H6`） | `selectors.responseContainer`（或 `selectors.assistantResponse` / `selectors.outlineHeadings`） |
| `outline-user-queries` | 在大纲中显示用户提问 | `selectors.userQuery` |
| `document-outline` | 独立侧栏文档/产物大纲 | 文档大纲源选择器 |
| `conversation-list` | 侧栏对话历史同步 | 对话列表选择器 *（目前由内置适配器使用）* |
| `export-basic` | 基础导出（Markdown / HTML / JSON / TXT / 图片） | `export`（`userQuerySelector` 与 `assistantResponseSelector`） |
| `model-lock` | 自动锁定模型 | 模型选择器配置 *（目前由内置适配器使用）* |
| `generation-detect` | 生成中/空闲状态检测（用于标签状态、完成提醒与队列） | `generation.stopButton` / `generation.loadingIndicator` 和/或 `networkMonitor` |
| `new-chat` | 发起新对话快捷键与按钮 | `selectors.newChatButton` 和/或 `session.newTabPath` |
| `stop-generation` | 停止生成快捷键 | `generation.stopButton` |
| `width` | 页面宽度与用户提问宽度调节 | `width` 选择器配置（`selectors`、`userQuerySelectors`） |
| `panel-avoidance` | 悬浮面板智能避让 | `panelAvoidance` 容器配置 |
| `zen` | 禅模式（隐藏侧栏与导航干扰） | `zenMode.hide` 选择器 |
| `clean` | 净化模式（隐藏推广与免责声明） | `cleanMode.hide` 选择器 |
| `prompt-insert` | 从词库、队列或链式提示词插入内容 | `selectors.textarea` 与 `input`（`mode`：`textarea` 或 `contenteditable`） |
| `reading-history` | 记录并自动恢复阅读滚动位置 | `session.idFromPathRegex` + `selectors.scrollContainer` |

## 常用顶层行为字段

以下行为通过顶层配置声明，不对应单独的能力 ID：

### `themeSync`（同步宿主页深浅主题）

没有单独的 `theme-sync` 能力 ID，直接在顶层配置 `themeSync` 对象即可：

- **`storageType`**：`"localStorage"`（默认）或 `"cookie"`（如 Perplexity 使用 Cookie；Cookie 模式仅支持扁平值，且未指定 `values.system` 时切换到跟随系统会删除该 Cookie）。
- **`storageKey`**：必填，`localStorage` 或 Cookie 键名。
- **`values`**：必填，`{ dark, light, system? }` 映射值。
- **`valuePath` / `valueFormat`**：`localStorage` 模式下，嵌套 JSON 对象用点分隔路径 `valuePath`（如 `"theme"`、`"appearance.mode"`），扁平值用 `valueFormat`（`"raw"` 或 `"json"`）；`valuePath` 与 `valueFormat: "json"` 互斥。
- **`timestampPath` / `staticFields`**：可选，与 `valuePath` 配合使用，用于同步写入时间戳或固定字段。
- **`extraKeys`**：可选，同时写入其他扁平 `localStorage` 键。
- **`domSync`**：可选数组 `{ selector, attributes?, classes? }`，用于同步命中元素（如 `html`、`body`）上的 `data-*` 属性（仅允许 `data-` 前缀）和含 `{mode}` 占位的类名模板（如 `["{mode}", "vscode-{mode}"]`）。

### 其他顶层标志与 `traits`

- **`outlineReverse: true`**：目标页面消息按倒序 DOM 排列（如 `flex-direction: column-reverse`）时声明。
- **`scrollPinRelease: true`**：目标页面在用户真实滚轮滚动前会持续吸底时，大纲跳转后补发零增量 wheel 事件解除吸底。
- **`traits.minimalEnhancements: true`**：启用精简增强模式（仅保留主题与面板避让），例如 Muse 适配包。
- **`traits.periodicOutlineRefresh: true`**：页面 DOM 变更事件不可靠时启用定时大纲刷新。
- **`mermaidSupport`**：站点未原生渲染 Mermaid 时设为 `"fallback"`。
- **`quickQuote`**：与站点自身选中浮层冲突时设为 `"disabled"`。

## 示例：Duck.ai 能力声明

```json
{
  "capabilities": [
    "outline",
    "outline-user-queries",
    "export-basic",
    "generation-detect",
    "new-chat",
    "stop-generation",
    "width",
    "zen",
    "prompt-insert"
  ]
}
```

完整配置可参考 [`registry/sites/duck-ai.json`](https://github.com/urzeye/ophel/blob/main/registry/sites/duck-ai.json)。
