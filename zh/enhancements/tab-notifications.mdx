同时开着多个 AI 标签页跑长任务时，Ophel 可以帮你一眼看清哪个页面还在生成、回答完第一时间提醒你，并在需要时伪装标签标题或估算当日调用次数与 Token 消耗。

## 标签页自动重命名

路径：**设置 → 功能模块 → 标签页**

| 设置项 | 可选项 | 默认值 | 所在位置与说明 |
| --- | --- | --- | --- |
| <Icon src="/images/icons/new-tab.svg" alt="新标签页图标" /> **新标签页打开按钮** | 开启 / 关闭 | 关闭 | 在面板标题栏右侧显示「新标签页」图标，一键在新标签打开当前站点首页。 |
| **自动重命名标签页** | 开启 / 关闭 | 开启 | 自动把标签页标题更新为当前对话名称与模型名。 |
| **显示状态图标** | 开启 / 关闭 | 开启 | 生成中显示 `⏳`，完成后显示 `✅`。 |
| **刷新间隔** | 1 / 3 / 5 / 10 / 30 / 60 秒 | 3 秒 | 底部 **高级选项** — 标签页在后台空闲时会自动降频至 ≥ 15 秒。 |
| **标题格式** | 自定义模板 | `{status}{title}->{model}` | 底部 **高级选项** — 支持 `{status}`、`{title}`、`{model}` 变量标签（例如 `⏳ 架构方案->GPT-4o`）。 |
| **已读后隐藏完成状态** | 开启 / 关闭 | 关闭 | 底部 **高级选项** — 切回该标签页查看后自动去掉 `✅` 图标。 |

### 隐私模式

位于 **设置 → 功能模块 → 标签页** 页面的 **隐私模式** 卡片中：

- <Icon src="/images/icons/eye-closed.svg" alt="隐私模式图标" /> **隐私模式**（默认 **关闭**）：把浏览器标签页标题伪装成普通网页名称，避免在公共场合或录屏时暴露对话主题。
- **伪装标题**：默认为 **`Google`**，可自由修改。

## 生成完成提醒

路径：**设置 → 功能模块 → 提醒**

| 设置项 | 可选项 | 默认值 | 所在位置与说明 |
| --- | --- | --- | --- |
| **桌面通知 / 生成完成提醒** | 开启 / 关闭 | 扩展默认 **关闭** / 油猴默认 **开启** | 完成提醒总开关（下方的提示音与音频设置均依赖开启此开关后才会生效）。扩展版首次开启时申请可选的 `notifications` 权限；macOS Safari 实验版不支持系统通知，此开关仅控制提示音。 |
| **提示音** | 开启 / 关闭 | 开启 | 生成完成时播放内置提示音（需开启上方总开关）。 |
| **提示音预设** | **默认**、**轻柔铃音**、**清脆玻璃音**、**明亮提醒** | **轻柔铃音** | 卡片内可直接点击 **试听** 按钮预览音效。 |
| **音量** | 10%–100% | 50% | 调节提示音播放音量。 |
| **播放次数** | 1 / 2 / 3 / 5 | 3 | 底部 **高级选项** — 提示音连续播放的次数。 |
| **重复间隔** | 1 / 2 / 3 / 5 / 10 秒 | 2 秒 | 底部 **高级选项** — 每次重复播放的间隔时长。 |
| **当前页面聚焦时也提醒** | 开启 / 关闭 | 关闭 | 底部 **高级选项** — 即使你正停留在当前对话标签页也发送提醒。 |
| **自动聚焦置顶窗口** | 开启 / 关闭 | 关闭 | 底部 **高级选项** — 生成完成后自动激活对应窗口和标签页。macOS Safari 不支持；油猴版仅支持当前窗口 `window.focus()`，无法还原最小化窗口。 |

## 高级模型用量估算

同样位于 **设置 → 功能模块 → 提醒** 页面，提供纯本地的发送次数记录与 Token 估算，方便你掌控有频率限制的高级模型额度：

| 设置项 | 可选项 | 默认值 | 说明 |
| --- | --- | --- | --- |
| **显示用量估算** | 开启 / 关闭 | 关闭 | 在对话输入框上方挂载紧凑状态条，实时显示今日已发次数、额度进度与单次请求/往返 Token 估算，支持一键手动归零。 |
| **每日发送次数上限** | 1–9999 | 100 | 本地参考上限，达到 80% 和 100% 时给出提醒。 |
| **每天自动清零（Beta）** | 开启 / 关闭 | 关闭 | 每天自动重置本地计数。 |

- **历史统计曲线**：卡片内直接提供可视化趋势图，支持按 **全部站点 / 当前站点** 筛选，切换 **小时 / 天 / 月** 粒度，并查看 5 项指标：**发送次数**、**单次请求估算**、**往返估算**、**已加载对话**、**已加载输出**。
- **估算说明**：Token 数由本地基于当前页面已加载内容按字符权重粗略估算，仅用于日常参考，不等同于平台官方计费口径。
