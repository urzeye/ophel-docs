Ophel 能接管浏览器标签页的标题显示，并在 AI 生成完成后主动通知你——即使你已经切到另一个标签页去做别的事。

## 标签页自动重命名

默认情况下，Ophel 会将浏览器标签页标题与 AI 对话标题保持同步，让你从标签栏一眼分辨多个对话窗口。

**设置 → 功能模块 → 标签页**：

| 设置项 | 说明 | 默认值 |
| --- | --- | --- |
| 自动重命名标签页 | 是否同步对话标题到浏览器标签页 | 开启 |
| 检测频率 | 轮询检查标题变化的间隔，可选 1 / 3 / 5 / 10 / 30 / 60 秒 | 3 秒 |
| 标题格式 | 自定义标签页标题模板，支持变量 `{status}`、`{title}`、`{model}` | `{status}{title}->{model}` |
| 显示生成状态 | 在标题中显示生成中 / 已完成图标（`⏳` / `✅`） | 开启 |
| 仅在未读时显示完成标记 | 只有完成回复尚未查看时才显示 `✅`，回到该标签页后自动隐藏 | 关闭 |

默认格式会生成类似 `⏳ 我的对话->GPT-4o`（生成中）和 `✅ 我的对话->GPT-4o`（已完成）的标题。

标题格式编辑器会把 `{status}`、`{title}`、`{model}` 高亮为占位符芯片，并提供按钮插入这些变量，减少手动输入占位符时的拼写错误。

<Tip>
  在 **设置 → 功能模块 → 标签页** 中开启 <Icon src="/images/icons/new-tab.svg" alt="新标签页图标" /> **新标签页打开新对话** 后，面板标题栏会显示新标签页按钮，点击即可在新浏览器标签页中新建对话。已有对话如需在新标签页打开，请使用对话行右侧的 <Icon src="/images/icons/more-horizontal.svg" alt="对话菜单图标" /> 菜单。
</Tip>

## 生成完成通知

AI 在另一个标签页里完成回复时，Ophel 可以通过桌面通知和声音提醒你。

**设置 → 功能模块 → 提醒**：

| 设置项 | 说明 | 默认值 |
| --- | --- | --- |
| 发送桌面通知 | 生成完成后发送桌面通知 | 关闭 |
| 通知声音 | 发送通知时是否同时播放提示音 | 开启 |
| 提示音预设 | 内置多种音效可选，可试听 | softChime |
| 声音音量 | 通知音量（10%–100%） | 50% |
| 播放次数 | 短音效重复播放的次数，可选 1 / 2 / 3 / 5 | 3 次 |
| 播放间隔 | 每次重复之间的间隔，可选 1 / 2 / 3 / 5 / 10 秒 | 2 秒 |
| 前台时也通知 | 当前标签页已激活时是否也发送通知 | 关闭 |
| 自动置顶窗口 | 生成完成后自动将浏览器窗口置于前台 | 关闭 |

<Note>
  首次启用"发送桌面通知"时，浏览器会请求 **notifications**
  权限，请选择"允许"。若之前拒绝过，可在 **设置 → 权限管理** 中补授。
</Note>

## 隐私模式

使用 AI 时不想让标签页标题暴露正在讨论的内容？隐私模式会用一个自定义文字替换浏览器标签页标题，完全屏蔽真实内容。

**设置 → 功能模块 → 标签页**：

| 设置项 | 说明 | 默认值 |
| --- | --- | --- |
| 隐私模式 | 开启后，标签页标题替换为自定义文字 | 关闭 |
| 伪装标题 | 替代显示的文字 | Google |

<Note>
  隐私模式只影响浏览器标签页标题显示，不影响 AI 对话内容本身，也不影响 Ophel
  面板内的任何功能。
</Note>
