和 AI 聊久了，页面动辄几十屏，想找回某段代码或结论只能拼命往上翻；常用提示词散落在记事本里；跨平台使用时每个网站的交互又各不相同。

Ophel Atlas 直接运行在你的 AI 对话页面内，在不同平台上提供一致的结构化工作台：实时大纲、文件夹与标签管理、提示词词库、多格式导出以及阅读与外观控制。

## 核心能力

## 支持的平台

Ophel 开箱内置 **16 个站点适配器**。具体可用功能取决于各平台本身的能力（例如没有侧栏历史列表的站点不会显示「对话」标签页）。

| 平台 | 匹配域名 | 说明 |
| --- | --- | --- |
| **ChatGPT** | `chatgpt.com` *（旧域名 `chat.openai.com` 会跳转至此）* | 完整功能；支持接口优先导出、按工作空间隔离对话、长对话渲染性能优化 |
| **Gemini** | `gemini.google.com` | 完整功能；支持文档大纲（Deep Research / Canvas）、生成图片去水印、输入框自动隐藏 |
| **Claude** | `claude.ai` | 完整功能；支持文档大纲（Artifact）、接口优先大纲与导出、按组织隔离对话、Session Key 账号切换 |
| **Google AI Studio** | `aistudio.google.com` | 完整功能；支持接口优先大纲与导出、默认折叠界面区块与屏蔽背景水印 |
| **Grok** | `grok.com` | 支持接口优先大纲、对话列表与导出；不支持净化模式 |
| **Gemini Notebook** | `notebook.google.com` | 精简增强模式：三源大纲（来源 / 对话 / Studio 产物）、提示词插入、面板避让、当前视图快照导出；无对话列表与模型锁定 |
| **Gemini Enterprise** | `business.gemini.google` | 新用户默认停用，可在 **设置 → 适配中心 → 内置站点** 中手动启用 |
| **DeepSeek** | `chat.deepseek.com` | 支持接口优先大纲与导出；不支持模型锁定 |
| **豆包 / Dola** | `www.doubao.com`、`www.dola.com` | 共用适配器，访问 `dola.com` 时显示为 **Dola**；两域名共享设置，本地对话与书签按域名隔离 |
| **Kimi** | `www.kimi.com`、`www.kimi.ai` | 完整功能；两个域名共享设置，本地对话与书签按域名隔离 |
| **Qwen Studio** | `chat.qwen.ai` | 支持接口优先大纲、对话列表与导出 |
| **通义千问（Qianwen）** | `www.qianwen.com`、`qianwen.com` | 无侧栏对话列表同步（自动隐藏对话标签页） |
| **腾讯元宝** | `yuanbao.tencent.com` | 完整功能；支持代码块自动换行 |
| **Z.ai** | `chat.z.ai`、`zchat.z.ai`、`www.zchat.z.ai` | 无侧栏对话列表同步（自动隐藏对话标签页）；`chat.z.ai` 与 `zchat.z.ai` 本地数据分开存放 |
| **智谱清言（ChatGLM）** | `chatglm.cn` | 无侧栏对话列表同步（自动隐藏对话标签页）；支持分享页接口导出 |
| **腾讯 ima** | `ima.qq.com` | 无侧栏对话列表同步（自动隐藏对话标签页）；不支持同步宿主页深浅主题 |

<Tip>
想在 Perplexity、WorkBuddy、Notion AI、Manus、Open WebUI 或 LibreChat 上使用？打开 **设置 → 适配中心** 即可安装另外 18 个社区适配包，或绑定你自己部署的站点。详见[适配中心](/zh/enhancements/site-extensions)。
</Tip>

## 本地优先与隐私原则

- **数据留在本地**：你的设置、文件夹、标签、提示词、书签和阅读进度都保存在浏览器本地存储（油猴版保存在脚本管理器本地存储）。
- **免账号、无广告、无埋点**：不需要注册或登录任何 Ophel 账号，扩展内部不包含广告或行为追踪脚本。
- **网络请求完全透明**：只有在你主动开启 WebDAV 同步、开启适配中心自动更新（每 24 小时拉取一次只读签名索引），或在卸载扩展后自愿提交匿名反馈问卷时，才会发起网络请求。详见[隐私说明](/zh/data/privacy)与[权限管理](/zh/data/permissions)。
- **GPLv3 开源**：全部源码公开在 [GitHub](https://github.com/urzeye/ophel)，可自由审查与构建。
