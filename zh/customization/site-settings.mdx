进入 **设置 → 站点设置**，在顶部下拉选择器中挑选任意内置平台或已安装适配包（当前所在站点会置顶；选中非当前站点时顶部会常驻提示条）。

选中站点后的全部配置集中在一页，分为四个区块：

1. **页面布局** — 智能避让、页面与提问宽度、禅模式、净化模式、自动隐藏输入框（详见[页面布局与显示](/zh/customization/layout)）。
2. **模型锁定** — 打开站点时自动切回你常用的模型。
3. **在指定页面隐藏 Ophel** — 按路径规则隐藏面板与快捷按钮。
4. **专属设置** — 仅针对 **Gemini**、**AI Studio**、**ChatGPT**、**Claude** 显示各自独有选项。

## 模型锁定

开启模型锁定后，每次打开或刷新该站点时，Ophel 会自动帮你选中目标模型；对话中途你依然可以手动切换其他模型，不会被强行切回去。

- **匹配方式**：填写不区分大小写的模型关键词（如 `pro`、`o3`、`sonnet`），自动匹配下拉菜单中第一项；在 **AI Studio** 上，Ophel 会直接抓取并缓存页面里的模型列表供你下拉选择。
- **快捷入口**：可在浮动 **工具箱 → 模型锁定** 快速开关，或按 <Shortcut combo="ctrl+alt+l" /> 直达设置。
- **支持的内置站点（14 / 16）**：ChatGPT、Gemini、Gemini Enterprise、AI Studio、Claude、Grok、豆包 / Dola、Kimi、Qwen Studio、通义千问（Qianwen）、腾讯元宝、智谱清言、腾讯 ima、Z.ai。*（**DeepSeek** 与 **Gemini Notebook** 不支持。）*

## 在指定页面隐藏 Ophel

如果你不想在某个站点的特定子页面（例如预览页或分享页）看到面板和快捷按钮，可以添加路径隐藏规则（后台核心模块仍会照常运行）：

- **通配符模式（默认）**：用 `*` 匹配路径中的任意字符（例如 `/artifact/*`）。
- **正则模式**：点击 `.*` 切换为正则表达式匹配（例如 `^/(artifact|share)/`）。
- 点击 **填入当前页面** 可一键带入当前标签页路径。

## 彻底停用某个站点

如果想让 Ophel 在某个内置平台上完全不加载，可以在以下任意一处停用：

- 在 **设置 → 站点设置** 选中该站点后，点击右上角的停用按钮。
- 在 **设置 → 适配中心 → 内置站点** 关闭对应开关。
- 在浏览器工具栏的 Ophel 弹窗中一键停用当前站点。

## Gemini 专属设置

选中 **Gemini** 时显示（快捷键 <Shortcut combo="ctrl+alt+g" />）：

| 设置项 | 默认值 | 说明 |
| --- | --- | --- |
| **Markdown 加粗修复** | 关闭 | 修复 Gemini 回复中偶发未正确渲染的 `**加粗**` 文本。 |
| **移除图片水印** | 关闭 | 移除 **Gemini AI 生成图片** 上的可见星形水印，覆盖页面预览、下载、复制以及 Markdown / ZIP 导出。 |

<Note>
**权限与平台说明**：在 Chrome、Edge 和 Firefox 扩展中，首次开启 Gemini 图片去水印会申请可选的 `<all_urls>` 权限，用于安全拉取并处理图片；油猴版无需额外弹窗即可使用；macOS Safari 实验版不支持此功能。
</Note>

- **MyStuff / Library 页面增强（自动生效）**：访问 Gemini 的 `/mystuff` 与 `/library` 页面时，Ophel 会自动为媒体卡片添加「在新标签页打开原对话」按钮，无需额外开关。

## AI Studio 专属设置

选中 **AI Studio** 时显示（默认模型选择位于同页的 **模型锁定** 卡片中）：

| 设置项 | 默认值 | 说明 |
| --- | --- | --- |
| **默认折叠侧边栏** | 关闭 | 打开页面时自动收起左侧导航栏 *（仅浏览器扩展预加载生效）*。 |
| **默认收起运行设置面板** | 关闭 | 打开页面时自动收起整个右侧运行设置栏 *（仅浏览器扩展预加载生效）*。 |
| **默认收起工具栏** | 关闭 | 默认折叠运行设置中的 Tools 区块 *（仅浏览器扩展预加载生效）*。 |
| **默认收起高级设置** | 关闭 | 默认折叠运行设置中的 Advanced Settings 区块 *（仅浏览器扩展预加载生效）*。 |
| **默认启用 Google 搜索工具** | **开启** | 默认保持开启联网搜索（Search grounding） *（仅浏览器扩展预加载生效）*。 |
| **移除水印** | 关闭 *（扩展）* | 屏蔽 AI Studio 页面背景中的 `watermark_v4.png` 水印（修改后需刷新；*仅浏览器扩展预加载生效*）。 |
| **Markdown 加粗修复** | 扩展关闭 / 油猴开启 | 修复回复中未渲染的 `**加粗**` 文本（扩展与油猴均生效）。 |

<Note>
除 **Markdown 加粗修复** 外，上述 AI Studio 开关均依赖扩展端的 `document_start` 预加载脚本，油猴版不会生效。
</Note>

## ChatGPT 专属设置

选中 **ChatGPT** 时显示：

| 设置项 | 默认值 | 说明 |
| --- | --- | --- |
| **Markdown 加粗修复** | 关闭 | 修复回复中偶发未渲染的 `**加粗**` 文本。 |
| **代码块批量挂载** | **开启** | 分批挂载代码编辑器，大幅缓解打开或切换超长代码对话时的卡顿。 |
| **流式渲染优化** | **开启** | 生成回复期间暂停消息区域的高开销过渡动画，降低 CPU/GPU 占用。 |
| **禁用页面毛玻璃** | 关闭 | 关闭页面 `backdrop-filter` 毛玻璃特效，减少超长对话滚动掉帧。 |

## Claude 专属设置（Session Key 多账号切换）

选中 **Claude** 时显示（快捷键 <Shortcut combo="ctrl+alt+c" />）。保存多个 Claude Session Key（格式 `sk-ant-sidXX-...`），无需反复退出重新登录即可切换账号：

- **添加与导入**：支持手动添加、JSON 导入导出（自动去重合并），扩展版还支持点击 **从浏览器导入**（需授予可选的 `cookies` 权限读取当前登录的 `sessionKey` Cookie）。
- **检测可用性**：支持单条 **检测** 或 **批量检测**（每条间隔 **500 ms**，自动识别有效性与账号类型）。
- **安全切换**：点击指定 Key 切换，或按 <Shortcut combo="ctrl+alt+s" /> 一键轮换到下一个可用 Key。扩展版在切换前会自动检测是否有其他 Claude 标签页正在生成回复，避免误打断。
- **油猴版差异**：支持手动/JSON 管理、测活以及在 `claude.ai` 页面内切换；不支持「从浏览器导入」与跨标签页生成检测。
- **组织隔离**：同步的 Claude 对话会按当前账号与组织自动隔离。

<Tip>
想找 **高级模型用量估算**（每日发送计数与 Token 趋势图）？它位于 **设置 → 功能模块 → 提醒**，详见[标签页、提醒与用量估算](/zh/enhancements/tab-notifications#高级模型用量估算)。
</Tip>
