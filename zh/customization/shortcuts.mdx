所有快捷键均可在 **设置 → 快捷键** 中自定义或禁用。

<Note>下表中，**Alt** 在 Mac 上为 `Option`；**Ctrl** 在 Mac 上为 `Cmd`。</Note>

## 导航

| 操作           | 默认快捷键 |
| -------------- | ---------- |
| 跳转到对话顶部 | `Alt+T`    |
| 跳转到对话底部 | `Alt+B`    |
| 返回锚点位置   | `Alt+Z`    |

## 面板

| 操作                       | 默认快捷键 |
| -------------------------- | ---------- |
| 打开/关闭面板              | `Alt+P`    || 切换面板模式（吸附↕悬浮）   | `Alt+M`    || 切换到第一个标签（大纲）   | `Alt+1`    |
| 切换到第二个标签（会话）   | `Alt+2`    |
| 切换到第三个标签（提示词） | `Alt+3`    |
| 切换亮色/暗色模式          | `Alt+D`    |
| 打开设置                   | `Alt+,`    |
| 查看快捷键列表             | `Alt+\`    |

## 大纲

| 操作               | 默认快捷键                    |
| ------------------ | ----------------------------- |
| 刷新大纲           | `Alt+R`                       |
| 一键展开/折叠全部  | `Alt+E`                       |
| 展开到 H1–H6       | `Alt+Shift+1` ~ `Alt+Shift+6` |
| 跳转到上一个标题   | `Alt+↑`                       |
| 跳转到下一个标题   | `Alt+↓`                       |
| 切换"我的问题"过滤 | `Alt+Q`                       |
| 切换"书签"过滤     | `Alt+C`                       |
| 定位当前位置到大纲 | `Alt+L`                       |
| 搜索大纲           | `Alt+F`                       |

## 会话

| 操作                 | 默认快捷键     |
| -------------------- | -------------- |
| 新建对话（新标签页） | `Ctrl+Shift+O` |
| 刷新会话列表         | `Alt+Shift+R`  |
| 定位当前会话         | `Alt+Shift+L`  |
| 上一个会话           | `Alt+[`        |
| 下一个会话           | `Alt+]`        |

## 编辑与操作

| 操作               | 默认快捷键     |
| ------------------ | -------------- |
| 停止 AI 生成       | `Alt+K`        |
| 聚焦到输入框       | `Alt+I`        |
| 打开全局搜索       | `Ctrl+K`       |
| 导出当前对话       | `Ctrl+Shift+E` |
| 复制最新 AI 回复   | `Ctrl+Shift+C` |
| 复制最后一个代码块 | `Alt+;`        |
| 切换滚动锁定       | `Alt+S`        |
| 切换禅模式         | `Ctrl+Shift+Z` |
| 切换提示词队列     | `Alt+J`        |
| 显示模型选择器     | `Alt+/`        |

## 如何自定义快捷键

<Steps>
  <Step title="打开设置">按 `Alt+,`（Mac: `Option+,`）打开设置弹窗。</Step>
  <Step title="进入快捷键页面">点击左侧导航的 **快捷键**。</Step>
  <Step title="修改或删除">
    - 点击任意快捷键行，然后按下新的组合键即可绑定 - 点击行末的 **×**
    可删除该快捷键 - 页面顶部的开关可以一键禁用所有快捷键
  </Step>
</Steps>
