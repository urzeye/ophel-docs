Ophel Atlas 坚持本地优先：不需要注册或登录任何 Ophel 账号，没有云端服务器托管你的对话，扩展内部也不嵌入任何广告或行为埋点。

## 你的数据存在哪里

你的设置、文件夹、标签、提示词、链式提示词、书签、阅读历史、本地用量估算以及已安装的站点适配包都保存在当前设备本地：

- **浏览器扩展（Chrome / Edge / Firefox / Safari）**：保存在浏览器的本地存储 `chrome.storage.local`。
- **油猴脚本（Tampermonkey / Violentmonkey / ScriptCat）**：保存在脚本管理器的本地 GM 存储（`GM_getValue` / `GM_setValue`）。

你的真实对话正文始终保存在各 AI 平台本身；Ophel 本地只保存标题、链接、文件夹归属、标签和置顶等轻量整理信息。

## 全部外部网络请求透明清单

Ophel 在后台**不做任何用户行为遥测**。产品中所有可能触发的外部网络请求仅限以下三类：

1. **WebDAV 同步与自动备份（默认关闭）**：仅在你主动填写并启用 WebDAV 后发生，请求由浏览器**直连你自己的 WebDAV 服务器**，不经过任何 Ophel 中转服务器。
2. **适配中心在线索引检查（默认开启，可随时关闭）**：在 **设置 → 适配中心 → 获取与更新** 开启「自动更新」时，每 24 小时向 jsDelivr（`cdn.jsdelivr.net`）或 GitHub（`raw.githubusercontent.com`）发起一次匿名只读 `GET` 请求，获取带 Ed25519 数字签名的索引文件，不携带 Cookie、账号或任何个人数据。
3. **可选卸载反馈问卷（仅 Chrome / Edge / Firefox）**：卸载扩展时，浏览器可能会打开 `https://ophel.app/uninstall/`，URL 仅附带版本号、浏览器类型、界面语言与安装天数等非个人参数。填写完全自愿；只有在你主动提交表单时，所选原因和补充说明才会以随机一次性 ID 发送至我们的 PostHog 项目，不收集账号、邮箱或任何可识别个人身份的信息。

## Claude Session Keys 安全提示

如果你使用 Claude 多账号切换功能，保存的 Session Keys（`sk-ant-sidXX-...`）会存放在本地存储中，并且会以明文包含在导出的**完整备份** JSON 文件以及所有 **WebDAV 备份**（手动与定时自动备份）中。请务必妥善保管备份文件并确保你的 WebDAV 存储私密安全。

## 权限透明原则

Ophel 遵循最小权限原则，非核心能力全部走按需可选权限，详细说明见[权限管理](/zh/data/permissions)。Firefox 扩展清单中明确声明 `data_collection_permissions: { required: ["none"] }`。

## 开源审计

Ophel Atlas 按 **GPLv3** 协议完全开源在 [GitHub](https://github.com/urzeye/ophel)，欢迎随时审查每一行源码或自行构建。
