Ophel 的设计原则是**隐私优先**。本页说明 Ophel 存储哪些数据、数据存在哪里，以及你对这些数据拥有完整控制权。

## 数据存储边界

Ophel 默认使用浏览器扩展本地存储（`chrome.storage.local`）保存数据，**不依赖任何 Ophel 账号或 Ophel 服务器**。如果你主动启用 WebDAV 同步，备份数据会发送到你配置的 WebDAV 服务器。

本地存储的数据包括：

- **设置（settings）** — 你在 Ophel 中配置的所有偏好项
- **提示词（prompts）** — 你保存的提示词库
- **会话元数据（conversations）** — 文件夹归属、标签、置顶状态（不含对话内容）
- **文件夹与标签（folders / tags）** — 分类管理数据
- **阅读历史（readingHistory）** — 各对话的上次阅读位置
- **Claude Session Keys（claudeSessionKeys）** — 仅在启用 Claude 多账号管理时保存

## Ophel 不会做什么

<Note>
  Ophel 不会收集、上传或分析你与 AI 的任何对话内容，不会追踪你的浏览行为，也不要求登录账号。除非你主动启用 WebDAV
  同步，Ophel 不会把本地数据发送到你配置之外的服务器。AI 平台上的实际消息内容属于你与对应 AI 服务之间的交互，Ophel
  不会访问或存储这些消息内容。
</Note>

## 可选权限

以下权限均为可选，仅在对应功能需要时请求，你可以随时在 **设置 → 权限** 中撤销：

| 权限            | 用途                                       | 撤销后的影响                  |
| --------------- | ------------------------------------------ | ----------------------------- |
| `notifications` | 发送 AI 生成完成桌面通知                   | 自动关闭完成通知功能          |
| `cookies`       | 读取 Claude Session Key 实现多账号切换     | 无法使用 Claude 多账号功能    |
| `<all_urls>`    | WebDAV 网络访问与图片去水印（Base64 转换） | WebDAV 同步和去水印功能不可用 |

## WebDAV 同步与隐私

如果你配置了 WebDAV 同步，Ophel 会将本地元数据上传到**你自己配置的 WebDAV 服务器**。Ophel 不作为同步中间方，数据直接从你的浏览器发送到你的服务器。

WebDAV 连接的凭证（用户名和密码）存储在本机 `chrome.storage.local` 中，不会被发送到除你配置的 WebDAV 地址以外的任何地方。

## Claude Session Keys

Claude Session Keys 存储在你本机的浏览器中，日常使用时仅用于代表你向 Claude 自己的接口（claude.ai）发送请求。Ophel 不会将它们发送到 Ophel 的服务器。

如果你使用完整备份或 WebDAV 同步，备份文件可能包含有效的 Session Keys。请妥善保管备份文件。

## 完整控制

你可以随时：

- 在 **设置 → 备份与同步** 中导出全部数据
- 在 **设置 → 备份与同步 → 清空所有数据** 中彻底删除 Ophel 存储的所有数据
- 直接卸载扩展，浏览器会清除相关存储
