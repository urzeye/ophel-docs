WebDAV 同步让你把 Ophel 数据上传到自己的私有服务器，并在多台设备之间保持一致。Ophel 内置了常用服务商的连接预设：

| 服务商       | 说明                                                |
| ------------ | ---------------------------------------------------- |
| **坚果云**      | 需在网页端生成应用密码，不能直接用登录密码 |
| **Infinicloud** | 固定 URL，开笱即用                              |
| **pCloud**   | 固定 URL，开笱即用                              |
| **Nextcloud** | 自托管，需填写自己的服务器地址                  |
| **Synology NAS** | 需先在套件中心安装 WebDAV Server 套件  |
| **Seafile**  | 自托管，需填写自己的服务器地址                  |
| **自定义**     | 其他任意 WebDAV 内容服务器                  |

## 配置 WebDAV

**设置 → 备份与同步 → WebDAV**：

| 配置项       | 说明                                                      |
| ------------ | --------------------------------------------------------- |
| 服务器地址   | WebDAV 服务器的完整 URL（以 `https://` 开头）             |
| 用户名       | WebDAV 账号用户名                                         |
| 密码         | WebDAV 账号密码（存储在本机，不上传给任何第三方）         |
| 远端目录     | 同步文件存放的路径（默认 `ophel`，自动创建）              |
| 同步模式     | 手动（点按钮）或自动（按设定间隔）                        |
| 自动同步间隔 | 自动模式下，两次同步之间的最短间隔（分钟）                |
| 数据来源     | 选择要同步的数据类型（设置 / 会话 / 提示词 / Claude Key） |

## 什么数据会被同步？

WebDAV 同步的是 Ophel 在本地维护的**元数据**：

- 你在 Ophel 中设置的文件夹、标签、置顶状态
- 提示词库
- Ophel 设置项
- Claude Session Key（可选，默认包含，共享备份文件时请注意）

<Note>
  WebDAV **不会同步** AI 平台上的实际对话消息——那些内容属于各 AI 服务，Ophel
  无权访问和上传。
</Note>

## 权限要求

<Warning>
  WebDAV 同步依赖可选权限 `<all_urls>`。首次启用时浏览器会弹出权限请求，请选择**允许**。可在 **设置 → 权限** 中随时查看或撤销。
</Warning>

## 多设备同步注意事项

- 多设备场景建议使用**手动同步**，避免多端同时写入产生冲突
- 建议将"自动同步"模式的间隔设置为不低于 5 分钟
- 同步前请确保服务器地址以 `https://` 开头（不支持 HTTP 明文传输）

## 常用 WebDAV 服务商配置说明

<AccordionGroup>
  <Accordion title="坚果云">
    首先在坚果云网页端进入【帐号信息】生成应用密码，用应用密码而非登录密码填写密码字段。URL 已自动填充为 `https://dav.jianguoyun.com/dav/`。
  </Accordion>
  <Accordion title="Nextcloud">
    将服务器地址填写为 `https://你的域名/remote.php/dav/files/用户名/`，用户名和密码即为 Nextcloud 登录凭证。
  </Accordion>
  <Accordion title="Synology NAS">
    先在群晖套件中心安装 **WebDAV Server** 套件并启用 HTTPS。服务器地址格式为 `https://你的NAS地址/webdav/`。
  </Accordion>
  <Accordion title="其他服务商">
    选择「自定义」并填写服务器地址。
  </Accordion>
</AccordionGroup>
