WebDAV 同步让你把 Ophel 数据上传到自己的私有服务器，并在多台设备之间保持一致。Ophel 内置了常用服务商的连接预设：

| 服务商           | 说明                                       |
| ---------------- | ------------------------------------------ |
| **坚果云**       | 需在网页端生成应用密码，不能直接用登录密码 |
| **InfiniCloud**  | 固定 URL，开箱即用                         |
| **pCloud**       | 固定 URL，开箱即用                         |
| **Nextcloud**    | 自托管，需填写自己的服务器地址             |
| **Synology NAS** | 需先在套件中心安装 WebDAV Server 套件      |
| **Seafile**      | 自托管，需填写自己的服务器地址             |
| **自定义**       | 其他任意 WebDAV 内容服务器                 |

## 配置 WebDAV

**设置 → 数据管理 → WebDAV 同步**：

| 配置项 | 说明 |
| --- | --- |
| 服务商 | 常用服务商预设（坚果云、InfiniCloud、Nextcloud 等）或自定义 |
| 服务器地址 | WebDAV 服务器的完整 URL（以 `https://` 开头） |
| 用户名 | WebDAV 账号用户名 |
| 密码 | WebDAV 账号密码（存储在本机，不上传给任何第三方） |
| 默认目录 | 同步文件存放的路径（默认 `ophel`，自动创建） |

## 首次设置步骤

<Steps>
  <Step title="打开 WebDAV 设置面板">
    前往 **设置 → 数据管理 → WebDAV 同步**。
  </Step>
  <Step title="填写服务器信息">
    输入服务器地址、用户名、密码和默认目录。如果目录不存在，Ophel 会在首次同步时自动创建。
  </Step>
  <Step title="授予所需权限">
    WebDAV 同步依赖可选权限 `<all_urls>`。首次启用时浏览器会弹出授权请求，请选择**允许**。
  </Step>
  <Step title="测试连接">
    点击 <Icon src="/images/icons/check.svg" alt="测试连接图标" /> **测试连接**，验证凭据和服务器可达性后再执行同步。
  </Step>
  <Step title="上传数据">
    点击 <Icon src="/images/icons/cloud-upload.svg" alt="上传备份图标" /> **上传**，将本地数据推送到服务器。
  </Step>
</Steps>

## 在新设备上恢复

<Steps>
  <Step title="配置相同的 WebDAV 服务器">
    在新设备上填入与原设备相同的服务器地址、用户名、密码和默认目录。
  </Step>
  <Step title="从服务器拉取数据">
    点击 <Icon src="/images/icons/download.svg" alt="从服务器拉取图标" /> **下载** 拉取最新备份；也可以在 **WebDAV 备份列表** 中选择历史快照恢复。
  </Step>
</Steps>

## 什么数据会被同步？

WebDAV 同步会备份 Ophel 在本地维护的数据：

- 你在 Ophel 中设置的文件夹、标签、置顶状态
- 提示词库
- Ophel 设置项
- Claude Session Key（如果你启用了 Claude 多账号管理）

<Note>
  WebDAV **不会同步** AI 平台上的实际对话消息——那些内容属于各 AI 服务，Ophel
  无权访问和上传。
</Note>

<Warning>
  如果你使用 Claude 多账号管理，WebDAV 备份文件可能包含有效的 Session Key。请妥善保管备份文件。
</Warning>

## 权限要求

<Warning>
  WebDAV 同步依赖可选权限 `<all_urls>`。首次启用时浏览器会弹出权限请求，请选择**允许**。可在 **设置 → 权限管理** 中随时查看或撤销。
</Warning>

## 多设备同步注意事项

- 多端同时写入可能产生冲突，建议在上传前先下载最新备份
- 同步前请确保服务器地址以 `https://` 开头（不支持 HTTP 明文传输）

## 常用 WebDAV 服务商配置说明

<AccordionGroup>
  <Accordion title="坚果云">
    首先在坚果云网页端的「安全选项」中生成「第三方应用密码」，用应用密码而非登录密码填写密码字段。URL
    已自动填充为 `https://dav.jianguoyun.com/dav/`。
  </Accordion>
  <Accordion title="Nextcloud">
    将服务器地址填写为
    `https://你的域名/remote.php/dav/files/用户名/`，用户名和密码即为 Nextcloud
    登录凭证。
  </Accordion>
  <Accordion title="Synology NAS">
    先在群晖套件中心安装 **WebDAV Server** 套件并启用 HTTPS。服务器地址格式为
    `https://你的NAS地址/webdav/`。
  </Accordion>
  <Accordion title="其他服务商">选择「自定义」并填写服务器地址。</Accordion>
</AccordionGroup>
