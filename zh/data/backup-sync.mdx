Ophel 的所有数据都保存在浏览器本地。进入 **设置 → 数据与权限 → 本地备份**，可以随时导出 JSON 文件留档，或迁移到新浏览器与新设备。

## 导出本地备份

提供三种导出粒度：

| 导出类型 | 包含内容 |
| --- | --- |
| <Icon src="/images/icons/backup.svg" alt="完整备份图标" /> **完整备份（推荐）** | 设置、提示词库、链式提示词、文件夹、标签、对话元数据（标题、链接、置顶）、阅读历史、Claude Session Keys、书签收藏、用量统计历史，以及已安装的站点适配包与自定义地址绑定。*（不包含 WebDAV 调度运行态、在线适配库缓存，也不包含 AI 平台上的聊天正文。）* |
| <Icon src="/images/icons/prompt.svg" alt="提示词图标" /> **仅提示词** | 提示词库与链式提示词。 |
| <Icon src="/images/icons/settings.svg" alt="设置图标" /> **仅设置** | 全部 Ophel 偏好、主题与布局设置。 |

<Warning>
如果你在 Ophel 中保存了 Claude Session Keys，**完整备份**会以明文 JSON 包含这些密钥。请妥善保存备份文件，切勿分享给他人或上传到公开仓库。
</Warning>

## 从备份恢复

1. 打开 **设置 → 数据与权限 → 本地备份**。
2. 拖入备份 <Icon src="/images/icons/json-file.svg" alt="JSON 文件图标" /> `.json` 文件、点击选择文件，或展开默认折叠的 **粘贴 JSON 文本** 区域直接粘贴内容。
3. 核对页面实时解析出的备份摘要预览，确认恢复后 Ophel 会自动写入并刷新相关标签页。

<Note>
**覆盖与合并的区别**：在 **本地备份** 中恢复会按备份文件包含的类型**覆盖**现有数据。如果你只想**合并**导入提示词而不删掉现有内容，请使用面板 **提示词** 标签页自带的 <Icon src="/images/icons/import.svg" alt="导入图标" /> 导入按钮；如果想合并 Claude Session Keys，请使用 **设置 → 站点设置 → Claude** 中的 JSON 导入。
</Note>

- **恢复后重新授权适配包**：如果备份中包含已安装的站点适配包或自定义站点地址，恢复后请前往 **设置 → 适配中心**，在顶部的 **重新授权已恢复的适配包** 区块中一键补授域名权限。

## 清除全部数据

页面底部的危险区提供 <Icon src="/images/icons/delete.svg" alt="清除数据图标" /> **清除全部数据**（带二次确认），执行后会不可逆地清空所有本地设置、文件夹、标签、提示词、书签、阅读记录与密钥，恢复到初次安装状态。你在各 AI 平台账号下的原始对话不会受影响。
