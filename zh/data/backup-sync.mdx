Ophel 的所有数据默认只保存在你本机的浏览器存储中。本页介绍如何将数据导出备份，以及如何在设备之间迁移。

## 本地备份（导出）

**设置 → 备份与同步**

支持将数据导出为 JSON 文件，以便备份或迁移到另一台设备：

| 导出类型 | 包含内容                                                                           |
| -------- | ---------------------------------------------------------------------------------- |
| <Icon src="/images/icons/backup.svg" alt="完整备份图标" /> 完整备份 | 所有数据：设置、提示词、会话元数据、文件夹、标签（以及可选的 Claude Session Keys） |
| <Icon src="/images/icons/prompt.svg" alt="提示词库图标" /> 仅提示词 | 提示词库 |
| <Icon src="/images/icons/settings.svg" alt="设置图标" /> 仅设置 | 所有配置项 |

<Warning>
  完整备份中**可选包含 Claude Session Keys**（默认启用）。这些 Key
  是有效的认证令牌，请妥善保管备份文件，避免分享给他人。
</Warning>

## 本地导入

将 <Icon src="/images/icons/json-file.svg" alt="JSON 文件图标" /> JSON 文件拖入或点击选择文件导入。Ophel 会在写入前对格式做校验，导入后自动刷新页面以使配置生效。

<Warning>导入会**覆盖**现有数据，建议在导入前先导出一份当前备份。</Warning>

## 清空所有数据

进入 **设置 → 备份与同步**，点击 <Icon src="/images/icons/delete.svg" alt="清空数据图标" /> **清空所有数据**。

删除 Ophel 存储的全部本地数据——包括提示词、会话元数据、文件夹、标签和所有设置，恢复到安装初始状态。

<Warning>此操作无法撤销。如需保留数据，请先导出完整备份。</Warning>
