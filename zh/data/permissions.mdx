Ophel 遵循**最小权限原则**：只申请功能所需的最小权限范围，且可选权限仅在你主动开启对应功能时才会请求。

![Ophel 权限管理设置面板](/images/panel/permission-zh.png)

## 权限类型

| 类型     | 权限            | 用途                                       |
| -------- | --------------- | ------------------------------------------ |
| 必需权限 | `storage`       | 保存配置与本地数据（安装时自动授予）       |
| 可选权限 | `notifications` | 生成完成桌面通知                           |
| 可选权限 | `cookies`       | Claude Session Key 读取与多账号切换        |
| 可选权限 | `<all_urls>`    | WebDAV 网络访问与图片去水印（Base64 转换） |

## 何时会请求可选权限

| 权限            | 触发时机                                                    |
| --------------- | ----------------------------------------------------------- |
| `notifications` | 首次启用**完成通知**时（**设置 → 功能 → 提醒 → 完成通知**） |
| `cookies`       | 首次使用 **Claude 多账号**功能时                            |
| `<all_urls>`    | 首次启用 **WebDAV 同步**或**去水印**时                      |

浏览器会弹出标准权限请求对话框，你可以选择允许或拒绝。

## 查看和撤销权限

<Steps>
  <Step title="打开设置">按 `Alt+,`（Mac: `Option+,`）打开 Ophel 设置。</Step>
  <Step title="进入权限页面">点击左侧导航中的 **权限**。</Step>
  <Step title="管理权限">
    页面会显示每项可选权限的当前状态。你可以点击**撤销**移除已授予的权限，或点击**请求**重新申请。
  </Step>
</Steps>

## 撤销权限后的影响

| 撤销的权限      | 影响                                              |
| --------------- | ------------------------------------------------- |
| `notifications` | **完成通知**功能自动关闭                          |
| `cookies`       | 无法读取 Claude Session Key，多账号切换功能不可用 |
| `<all_urls>`    | WebDAV 同步停止工作；去水印功能不可用             |

<Note>
  撤销权限不会删除你已有的数据或设置。重新授予权限后，对应功能将恢复正常。
</Note>
