Ophel 遵循**最小权限原则**：只申请功能所需的最小权限范围。必需权限在安装时通过扩展清单授予，可选权限绝不会静默授予——你的浏览器会在你首次激活依赖该权限的功能时提示你，你也可以随时在 **设置 → 权限** 中撤销任何已授予的权限。

![Ophel 权限管理设置面板](/images/panel/permission-zh.png)

## 必需权限

这些权限始终处于激活状态。没有它们，Ophel 无法正常运行。

| 权限 | 用途 |
| --- | --- |
| `storage` | 将设置、提示词、文件夹、标签和会话元数据保存到浏览器本地存储 |
| `declarativeNetRequestWithHostAccess` | 在 Claude 页面上应用声明式网络请求规则（用于请求头修改） |

## 可选权限

这些权限默认关闭。Ophel 在你首次使用依赖该权限的功能时，通过浏览器弹窗请求授权。

| 权限 | 功能 |
| --- | --- |
| `notifications` | AI 回复生成完成时的桌面通知 |
| `cookies` | 读取和切换 Claude Session Key，支持多账号 |
| `<all_urls>` | WebDAV 同步请求到你自己的服务器，以及去水印功能 |

## 授予权限

无需提前手动授予可选权限。当你开启某个需要权限的功能时（例如启用 WebDAV 同步或完成通知），浏览器会自动弹出标准权限请求。点击**允许**即可授予。

<Note>
  如果你不小心关掉了浏览器权限弹窗，进入 **设置 → 权限**，使用其中的授权控件重新触发请求。
</Note>

## 撤销权限

进入 **设置 → 权限**，每个可选权限都有**撤销**按钮。撤销权限后，依赖该权限的功能会自动禁用，无需逐一手动关闭。

| 撤销的权限 | 自动禁用的功能 |
| --- | --- |
| `notifications` | 桌面完成通知 |
| `cookies` | Claude Session Key 读取与多账号切换 |
| `<all_urls>` | WebDAV 同步、去水印 |

<Warning>
  撤销 `<all_urls>` 会同时禁用 WebDAV 同步和去水印，因为两者都依赖广泛的主机访问权限。如果只想禁用其中一个，请在各自的功能设置中关闭，而不是撤销权限。
</Warning>



## 站点扩展包主机访问

站点扩展包对每个扩展包源使用**可选主机权限**，而不是安装时永久授予大范围主机权限。当你安装扩展包或绑定自定义 HTTPS 源时，浏览器只会请求这些源的访问权限。拒绝提示会回滚该次安装或绑定。

油猴构建无法自动添加 `@match` 规则；站点扩展包页会列出你需要自行添加的模式。

完整权限、重新授权与自定义源流程见[安装与管理站点扩展包](/zh/site-packs/installation)。

## 常见问题

<AccordionGroup>
  <Accordion title="为什么 WebDAV 同步需要 <all_urls>？">
    WebDAV 服务器可以托管在任意 URL，Ophel 无法提前在清单中声明一个固定的主机名。`<all_urls>` 权限允许 Ophel 向你配置的任何服务器地址发起网络请求，请求只会发送到你自己的 WebDAV 服务器。
  </Accordion>
  <Accordion title="cookies 权限实际访问了什么？">
    `cookies` 权限让 Ophel 读取 Claude 域名上的会话 Cookie，以便你存储和切换多个 Claude 账号（Claude Session Key）。Ophel 不会读取其他网站的 Cookie。
  </Accordion>
  <Accordion title="不授予任何可选权限能正常使用 Ophel 吗？">
    可以。所有可选权限默认关闭。核心功能——会话整理、提示词库、大纲面板、主题、本地备份/恢复——无需任何可选权限即可正常使用。
  </Accordion>
</AccordionGroup>
