Ophel 安装时只申请核心运行所需的最小权限，其余能力全部采用**按需可选权限**，只有当你主动开启对应功能时才会弹出授权提示。

浏览器扩展用户可随时前往 **设置 → 数据与权限 → 权限管理** 查看并撤销可选权限（油猴版不涉及扩展权限 API，因此隐藏此标签页）。

## 必需权限

以下权限在安装扩展时即声明在 `manifest.json` 中：

| 权限 | 适用浏览器 | 真实用途 |
| --- | --- | --- |
| `storage` *（Safari 另含 `unlimitedStorage`）* | 全部扩展 | 在本地保存你的设置、文件夹、标签、提示词、书签、阅读历史与站点适配包。 |
| `alarms` | 全部扩展 | 后台定时调度 WebDAV 自动备份与适配中心 24 小时索引检查。 |
| `declarativeNetRequestWithHostAccess` | Chrome、Edge、Firefox *（Safari 不使用）* | **仅用于 Gemini 去水印与附件下载**：只对扩展后台发往 `*.googleusercontent.com` 与 `*.google.com` 的请求补充 `Referer`、`Origin` 与 CORS 响应头（明确排除页面自身请求），不涉及浏览记录或聊天读取。 |
| `host_permissions`（28 条内置站点与附件 CDN 域名） | 全部扩展 | 让 Ophel 在 16 个内置 AI 平台挂载工作台，并在导出 ZIP 附件或去水印时读取官方 CDN 图片与文件。 |
| `scripting` *（构建时注入）* | 全部扩展 | 注入页面辅助脚本，并为你安装的站点适配包动态注册内容脚本。 |

## 按需可选权限

以下权限默认**不授予**，只有当你使用对应功能时才会按需申请：

| 权限 | 触发场景 | 撤销后会发生什么 |
| --- | --- | --- |
| `notifications` *（Safari 不支持）* | 在 **设置 → 功能模块 → 提醒** 开启 **桌面通知** | 自动关闭完成提醒主开关（桌面通知与提示音均会停止；标签状态图标与自动聚焦不受影响）。 |
| `cookies` | 在 **设置 → 站点设置 → Claude** 点击 **从浏览器导入** 或切换 Session Key | 无法再读取或写入 `claude.ai` 的 `sessionKey` Cookie。 |
| `<all_urls>` *（高级主机访问）* | 开启 **WebDAV 同步**（Chrome/Edge/Firefox）或 **Gemini 移除图片水印** | 自动关闭 Gemini 去水印并停止 WebDAV 跨主机请求；已安装的站点适配包不会被删，而是退回按单域名授权。 |
| **站点适配包单域名权限** | 安装社区适配包或绑定自部署站点地址 | 该站点暂停加载 Ophel，直到重新授权；卸载适配包或删掉绑定后会自动回收不再使用的托管域名权限。 |

<Note>
授予 `<all_urls>` 后，同时也会覆盖已安装站点适配包的域名权限以及导出图片附件时的跨域抓取，无需逐个站点反复弹窗。
</Note>

## 如何授权与撤销

- **Chrome / Edge / Firefox**：进入 **设置 → 数据与权限 → 权限管理**，可查看每项可选权限的实时状态并一键 **允许** 或 **撤销**。如果在 AI 页面的设置弹窗内触发授权，Ophel 会弹出一个独立的权限确认窗口以调起浏览器原生授权框。
- **Safari（macOS 实验版）**：Safari 不支持由扩展弹窗申请网站权限，请前往 **Safari → 设置 → 扩展 → Ophel Atlas** 手动勾选需要放行的 AI 站点或 WebDAV 服务器域名。
- **油猴脚本**：由脚本管理器的 `@match` / `@connect` 规则统一控制，无需也无权调用浏览器扩展权限管理页。
