## 平台与安装

<AccordionGroup>
  <Accordion title="Ophel 支持哪些 AI 平台？">
    开箱内置 **16 个主流平台**（含豆包/Dola、Kimi `.com`/`.ai`、Z.ai 等多域名站点），另在适配中心提供 **18 个社区站点适配包**（包含 Open WebUI、LibreChat、NextChat 等自部署应用）。完整清单见[产品简介 — 支持的平台](/zh/introduction#支持的平台)与[适配中心概览](/zh/enhancements/site-extensions)。
  </Accordion>

  <Accordion title="浏览器扩展、macOS Safari 和油猴脚本该怎么选？">
    - **Chrome / Edge / Firefox 扩展**：能力最完整，包含按需权限管理、浏览器全局快捷键 <Shortcut combo="alt+o" />、后台 `alarms` 定时自动备份、Claude 从浏览器导入 Cookie 以及 AI Studio 预加载优化。
    - **油猴脚本**（Tampermonkey / Violentmonkey / ScriptCat）：适用于任何装有脚本管理器的浏览器，核心功能、WebDAV、桌面通知与 Gemini 去水印都可用；不含浏览器全局快捷键与 Claude 浏览器 Cookie 导入。
    - **Safari（macOS 实验版）**：受限于临时扩展机制（24 小时或退出 Safari 自动失效），不支持系统桌面通知、自动聚焦窗口与 Gemini 图片去水印。

    完整对照见[安装指南 — 各平台能力对比](/zh/installation#各平台能力对比)。
  </Accordion>

  <Accordion title="Ophel 免费开源吗？需要填 API Key 吗？">
    免费且按 **GPLv3** 协议开源在 [GitHub](https://github.com/urzeye/ophel)。不需要注册账号，也不需要填写任何 API Key，直接增强你平时使用的 AI 网页。
  </Accordion>
</AccordionGroup>

## 功能与使用

<AccordionGroup>
  <Accordion title="为什么部分站点看不到「对话」标签页？">
    只有提供侧栏历史对话列表的 **11 个内置平台** 会显示「对话」标签页（ChatGPT、Gemini、Gemini Enterprise、AI Studio、Claude、Grok、DeepSeek、豆包/Dola、Kimi、Qwen Studio、腾讯元宝）。其余 5 个内置平台（Gemini Notebook、智谱清言、腾讯 ima、通义千问、Z.ai）以及当前社区适配包会自动隐藏该标签并跳过同步。
  </Accordion>

  <Accordion title="文件夹支持多级嵌套吗？">
    当前文件夹为单层平级结构，配合不限数量的彩色 **标签** 和 **置顶** 使用。用文件夹区分大项目、用标签做多维标记，拖拽归类和全局搜索（`folder:`、`tag:`）都会更高效。
  </Accordion>

  <Accordion title="切换账号、工作空间或域名时，对话记录会串台吗？">
    不会。Ophel 会按登录账号或工作空间隔离本地对话（例如 ChatGPT 个人与团队空间、Claude 不同组织）；对于多域名内置站点（豆包与 Dola、Kimi `.com` 与 `.ai`、Z.ai `chat.z.ai` 与 `zchat.z.ai`），设置项共享，本地对话、书签与阅读历史按域名隔离。
  </Accordion>

  <Accordion title="在 Ophel 里删除对话，会把 AI 网站上的原对话也删掉吗？">
    默认**会**——**设置 → 功能模块 → 对话** 中的 **删除对话时同步删除站点上的对话** 默认为开启，删除时会同时删除支持平台上的原对话且无法恢复。如果你只想删掉 Ophel 本地记录，请关闭此开关。（注意：「缺失对话审阅」弹窗中的清理始终只删本地记录，不会动原站点。）
  </Accordion>

  <Accordion title="以前能看到的某些设置项为什么找不到了？">
    为了保持设置页清爽，**大纲**、**导出**、**标签页**、**提醒**、**内容交互** 卡片中的低频选项收进了各自卡片底部的 **高级选项** 折叠区；快捷键中的「切换面板标签」和「展开到指定层级」同样默认折叠。也可以直接按 <Shortcut combo="ctrl+k" /> 在全局搜索中按名字（兼容旧名称）直达对应设置。
  </Accordion>

  <Accordion title="为什么设置侧栏里没有「外观主题」或「权限管理」？">
    - **外观主题**：如果你直接打开独立的扩展选项页（没有挂载在 AI 网页内），该入口会自动隐藏；请在任意受支持的 AI 页面中点击面板设置按钮进入。
    - **权限管理**：油猴版由脚本管理器通过 `@match` / `@connect` 控制权限，不显示扩展权限管理页。
  </Accordion>
</AccordionGroup>

## 数据、同步与隐私

<AccordionGroup>
  <Accordion title="数据存在哪里？换电脑或换浏览器怎么迁移？">
    全部数据默认保存在你的浏览器本地存储（扩展用 `chrome.storage.local`，油猴用脚本管理器本地存储）。换设备时可在 **设置 → 数据与权限 → 本地备份** 导出完整 JSON 文件，或配置 [WebDAV 同步与定时自动备份](/zh/data/webdav)。
  </Accordion>

  <Accordion title="Ophel 会把我的聊天内容上传到服务器吗？">
    不会。对话正文始终留在 AI 平台，Ophel 没有收集对话的后端服务器。关于所有可能触发的可选网络请求（自建 WebDAV、在线适配库签名检查、自愿提交的卸载问卷），见[隐私说明](/zh/data/privacy)。
  </Accordion>

  <Accordion title="如何清空全部数据恢复出厂设置？">
    前往 **设置 → 数据与权限 → 本地备份**，点击底部的 **清除全部数据** 并确认即可。该操作仅清空 Ophel 本地数据，不会影响 AI 网站上的历史对话。
  </Accordion>
</AccordionGroup>
