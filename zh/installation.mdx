Ophel Atlas 由同一套源码构建为**浏览器扩展**与**油猴脚本**两种形态，你可以按自己的浏览器环境选择。

<Tip>
优先推荐使用浏览器扩展（Chrome / Edge / Firefox），能获得完整能力，包括按需权限管理、浏览器全局快捷键以及从浏览器 Cookie 导入 Claude Session Key。如果你受限无法安装扩展，或使用其他支持油猴脚本的浏览器，可选择油猴版。
</Tip>

## 各平台能力对比

安装前可以先看下不同浏览器和油猴版本的真实差异：

| 能力 | Chrome / Edge | Firefox | Safari（macOS 实验版） | 油猴脚本 |
| --- | --- | --- | --- | --- |
| 核心功能（大纲、对话、提示词、导出、全局搜索、主题、布局） | 完整支持 | 完整支持 | 完整支持 | 完整支持 |
| 适配中心与自部署站点绑定 | 完整支持（按站点弹窗授权） | 完整支持（按站点弹窗授权） | 完整支持（在 Safari 设置中授权网站访问） | 完整支持（免权限弹窗，按白名单运行） |
| WebDAV 手动备份与定时自动备份 | 完整支持（后台 `alarms` 定时） | 完整支持（后台 `alarms` 定时） | 完整支持（需在 Safari 设置中允许目标服务器域名） | 完整支持（定时备份需保持至少一个支持页面打开） |
| 回复完成桌面通知 | 按需申请 `notifications` 权限（默认关） | 按需申请 `notifications` 权限（默认关） | 不支持（页面提示音与标签状态图标仍可用） | 通过 `GM_notification` 支持（默认开） |
| 生成完成后自动聚焦置顶窗口 | 支持 | 支持 | 不支持 | 部分支持（仅 `window.focus()`，无法还原最小化窗口） |
| Gemini 生成图片去水印 | 按需申请 `<all_urls>` 权限 | 按需申请 `<all_urls>` 权限 | 不支持 | 支持 |
| Claude Session Key 多账号切换 | 完整支持（含从浏览器导入与跨标签生成检测） | 完整支持（含从浏览器导入与跨标签生成检测） | 完整支持（手动/JSON 管理，支持 Cookie 权限） | 部分支持（支持手动/JSON 与在 `claude.ai` 切换；不支持浏览器导入与跨标签检测） |
| 浏览器全局快捷键（<Shortcut combo="alt+o" />） | 支持 | 支持 | 支持 | 不支持（页面内全部快捷键均正常可用） |
| AI Studio 预加载优化（启动折叠与背景水印屏蔽） | 支持 | 支持 | 支持 | 不支持（油猴无预加载入口） |
| 重启浏览器后保留 | 持久保留 | 持久保留（通过 AMO 安装） | **临时扩展（24 小时或退出 Safari 即失效）** | 持久保留 |

## 从商店或脚本站安装

<Tabs>
  <Tab title="Chrome / Chromium 浏览器">
    <Steps>
      <Step title="打开 Chrome 网上应用店">
        访问 [Ophel Atlas 商店页面](https://chromewebstore.google.com/detail/ai-chat-organizer-outline/lpcohdfbomkgepfladogodgeoppclakd)。
      </Step>
      <Step title="添加扩展">
        点击 **添加至 Chrome**（或对应浏览器名称），在弹窗中确认安装。
      </Step>
      <Step title="打开 AI 网站">
        打开任意[支持的平台](/zh/introduction#支持的平台)。如果页面之前已经打开，刷新一次即可看到面板。
      </Step>
    </Steps>
  </Tab>

  <Tab title="Microsoft Edge">
    <Steps>
      <Step title="打开 Edge 外接程序商店">
        访问 [Ophel Atlas Edge 商店页面](https://microsoftedge.microsoft.com/addons/detail/ophel-atlas-ai-chat-navi/ffpenkdeifijngifjmbbpijfpdhlolga)。
      </Step>
      <Step title="安装扩展">
        点击 **获取**，然后点击 **添加扩展**。
      </Step>
      <Step title="打开 AI 网站">
        打开或刷新任意[支持的平台](/zh/introduction#支持的平台)。
      </Step>
    </Steps>
  </Tab>

  <Tab title="Firefox">
    <Steps>
      <Step title="打开 Firefox 附加组件商店">
        访问 [Ophel Atlas Firefox 商店页面](https://addons.mozilla.org/firefox/addon/ophel-ai-chat-enhancer/)（需要 Firefox 109 或更高版本）。
      </Step>
      <Step title="添加到 Firefox">
        点击 **添加到 Firefox** 并确认权限提示。
      </Step>
      <Step title="打开 AI 网站">
        打开或刷新任意[支持的平台](/zh/introduction#支持的平台)。
      </Step>
    </Steps>
  </Tab>

  <Tab title="油猴脚本（Greasy Fork / ScriptCat）">
    <Steps>
      <Step title="安装脚本管理器">
        在浏览器中安装 [Tampermonkey（篡改猴）](https://www.tampermonkey.net/)、[Violentmonkey（暴力猴）](https://violentmonkey.github.io/) 或 [ScriptCat（脚本猫）](https://docs.scriptcat.org/)。
      </Step>
      <Step title="安装 Ophel 脚本">
        前往 [Greasy Fork](https://greasyfork.org/scripts/563646-ophel-ai-chat-page-enhancer) 或 [ScriptCat](https://scriptcat.org/script-show-page/6519)，点击安装并在脚本管理器中确认。
      </Step>
      <Step title="打开 AI 网站">
        打开或刷新任意[支持的平台](/zh/introduction#支持的平台)。
      </Step>
    </Steps>

    <Note>
    油猴版通过按版本固定的 `@require` / `@resource` 加载资源并附带 `#sha256=` 完整性校验；访问非支持页面时会在初始化前直接退出，不影响其他网页。
    </Note>
  </Tab>
</Tabs>

## 从 GitHub Releases 手动安装

如果你想抢先体验刚发布的新版本、离线安装，或试用 macOS Safari 实验版，可以从 [GitHub Releases](https://github.com/urzeye/ophel/releases) 下载对应构建包。

<Warning>
请**不要**手动加载 `*-cws-upload.zip` 或 `*-edge-addons-upload.zip`。这两个压缩包专供应用商店上传，移除了本地加载所需的清单信息。
</Warning>

<Tabs>
  <Tab title="Chrome / Edge">
    <Steps>
      <Step title="下载并解压">
        下载 `ophel-atlas-vX.X.X-chrome.zip` 并解压到一个固定目录（不要删除解压目录，否则扩展会失效）。
      </Step>
      <Step title="打开扩展管理页">
        地址栏输入 `chrome://extensions`（Chrome）或 `edge://extensions`（Edge），打开右上角 **开发者模式**。
      </Step>
      <Step title="加载已解压的扩展程序">
        点击 **加载已解压的扩展程序**，选择包含 `manifest.json` 的解压文件夹。
      </Step>
    </Steps>
  </Tab>

  <Tab title="Firefox">
    <Warning>
    GitHub Releases 提供的是未签名 ZIP 包（`ophel-atlas-vX.X.X-firefox.zip`），通过 `about:debugging` 临时加载会在重启 Firefox 后自动卸载。日常使用请直接从 [Firefox 附加组件商店（AMO）](https://addons.mozilla.org/firefox/addon/ophel-ai-chat-enhancer/) 安装。
    </Warning>

    <Steps>
      <Step title="下载并解压">
        下载 `ophel-atlas-vX.X.X-firefox.zip` 并解压。
      </Step>
      <Step title="打开调试页">
        地址栏访问 `about:debugging#/runtime/this-firefox`。
      </Step>
      <Step title="临时载入附加组件">
        点击 **临时载入附加组件…**，选择解压目录中的 `manifest.json`。
      </Step>
    </Steps>
  </Tab>

  <Tab title="Safari（macOS 实验版）">
    <Warning>
    桌面端 Safari 目前属于**实验适配**，仅支持以本地临时扩展方式运行：**24 小时后或退出 Safari 时会自动移除**。目前没有已签名的 Safari App Store 版本，也不支持 iOS Safari。
    </Warning>

    <Steps>
      <Step title="下载并解压">
        从 GitHub Releases 下载 `ophel-atlas-vX.X.X-safari.zip` 并解压。无需安装 Xcode，也不需要付费 Apple 开发者账号。
      </Step>
      <Step title="开启开发者功能">
        打开 **Safari → 设置 → 高级**，勾选 **显示网页开发者功能**。
      </Step>
      <Step title="添加临时扩展">
        进入 **Safari → 设置 → 开发者**（或顶部 **开发** 菜单），点击 **添加临时扩展…**，选择包含 `manifest.json` 的解压目录。
      </Step>
      <Step title="允许网站访问">
        打开 **Safari → 设置 → 扩展**，勾选启用 **Ophel Atlas**，并允许其访问你使用的 AI 站点。
      </Step>
    </Steps>
  </Tab>

  <Tab title="油猴脚本">
    <Steps>
      <Step title="下载脚本文件">
        从 GitHub Releases 下载 `ophel-atlas-vX.X.X.user.js`。
      </Step>
      <Step title="导入脚本管理器">
        将 `.user.js` 文件拖入浏览器窗口，或在脚本管理器面板中手动导入安装。
      </Step>
    </Steps>
  </Tab>
</Tabs>
