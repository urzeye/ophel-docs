和 AI 聊久了，页面动辄几十屏，想找回某段代码或结论只能拼命往上翻；常用提示词散落在记事本里；跨平台使用时每个网站的交互又各不相同。

Ophel Atlas 以浏览器扩展或油猴脚本的形式直接运行在你的 AI 对话页面内，在不同平台上提供一致的结构化侧边工作台：实时大纲、文件夹与标签管理、提示词词库、多格式导出以及阅读与外观控制。所有数据默认只保存在你的浏览器本地，不需要注册账号，也不需要填写 API Key。

## 核心能力

<CardGroup cols={2}>
  <Card title="实时大纲" icon="/images/icons/outline.svg" href="/zh/features/outline">
    随回答生成实时提取提问与多级标题，支持层级折叠、搜索过滤、重点收藏、字数统计与单节复制。
  </Card>
  <Card title="对话管理与导出" icon="/images/icons/conversation.svg" href="/zh/features/conversations">
    用文件夹、标签和置顶整理已同步对话，支持批量操作，并可导出完整对话或选定片段为 Markdown、带图片 ZIP、HTML、JSON、TXT 或分享图片。
  </Card>
  <Card title="提示词词库、队列与链" icon="/images/icons/prompt.svg" href="/zh/features/prompts">
    用 `{{变量}}` 模板、默认值和下拉选项复用提示词，支持划词引用、提示词队列自动顺序发送以及多步链式提示词。
  </Card>
  <Card title="全局搜索" icon="/images/icons/search.svg" href="/zh/features/global-search">
    按 <Shortcut combo="ctrl+k" /> 快速检索当前大纲、跨平台对话、提示词、设置项与功能技巧，支持 `type:`、`folder:`、`tag:`、`is:`、`level:`、`date:` 与 `tip:` 语法。
  </Card>
  <Card title="阅读与内容增强" icon="/images/icons/features.svg" href="/zh/enhancements/content">
    支持用户提问 Markdown 渲染、公式双击复制（LaTeX / MathML）、表格一键复制 Markdown、Mermaid 图表渲染、滚动锁定与阅读进度恢复。
  </Card>
  <Card title="主题、布局与站点控制" icon="/images/icons/appearance.svg" href="/zh/customization/appearance">
    内置 24 套主题并支持自定义 CSS；可调宽屏、禅模式、净化模式、站点模型锁定，并通过你自己的 WebDAV 服务器实现多端备份与同步。
  </Card>
</CardGroup>

## 三步快速上手

<Steps>
  <Step title="安装 Ophel Atlas">
    在 Chrome、Edge、Firefox、macOS Safari（实验版）或油猴脚本管理器（Greasy Fork / ScriptCat）中安装。完整下载渠道与各平台能力差异见[安装指南](/zh/installation)。
  </Step>
  <Step title="打开任意支持的 AI 网站">
    访问 ChatGPT、Gemini、Claude、DeepSeek 或下方任意内置平台。首次使用时确认本地使用声明，系统会自动带你走一遍 4 步聚光灯引导（大纲、对话、提示词与设置入口）。
  </Step>
  <Step title="在侧边面板中开始使用">
    用大纲在长回复中快速定位，把重要对话归入文件夹或打标签，从词库一键插入提示词，或按 <Shortcut combo="ctrl+k" /> 打开全局搜索。详见[面板概览](/zh/panel-overview)。
  </Step>
</Steps>

## 支持的平台

Ophel 开箱内置 **16 个站点适配器**。具体可用功能取决于各平台本身的能力（例如没有侧栏历史列表的站点不会显示「对话」标签页）。

| 平台 | 匹配域名 | 说明 |
| --- | --- | --- |
| <Icon src="/images/icons/chatgpt.png" alt="ChatGPT 图标" /> **ChatGPT** | `chatgpt.com` *（旧域名 `chat.openai.com` 会跳转至此）* | 完整功能；支持接口优先导出、按工作空间隔离对话、长对话渲染性能优化 |
| <Icon src="/images/icons/gemini.png" alt="Gemini 图标" /> **Gemini** | `gemini.google.com` | 完整功能；支持文档大纲（Deep Research / Canvas）、生成图片去水印、输入框自动隐藏 |
| <Icon src="/images/icons/claude.svg" alt="Claude 图标" /> **Claude** | `claude.ai` | 完整功能；支持文档大纲（Artifact）、接口优先大纲与导出、按组织隔离对话、Session Key 账号切换 |

| <Icon src="/images/icons/gemini-enterprise.png" alt="Gemini Enterprise 图标" /> **Gemini Enterprise** | `business.gemini.google` | 新用户默认停用，可在 **设置 → 适配中心 → 内置站点** 中手动启用 |

| <Icon src="/images/icons/qwenai.png" alt="Qwen Studio 图标" /> **Qwen Studio** | `chat.qwen.ai` | 支持接口优先大纲、对话列表与导出 |

## 本地优先与隐私原则

- **数据留在本地**：你的设置、文件夹、标签、提示词、书签和阅读进度都保存在浏览器本地存储（油猴版保存在脚本管理器本地存储）。
- **免账号、无广告、无埋点**：不需要注册或登录任何 Ophel 账号，扩展内部不包含广告或行为追踪脚本。
- **网络请求完全透明**：只有在你主动开启 WebDAV 同步、开启适配中心自动更新（每 24 小时拉取一次只读签名索引），或在卸载扩展后自愿提交匿名反馈问卷时，才会发起网络请求。详见[隐私说明](/zh/data/privacy)与[权限管理](/zh/data/permissions)。
- **GPLv3 开源**：全部源码公开在 [GitHub](https://github.com/urzeye/ophel)，可自由审查与构建。
