你可以把整场对话——或者只挑出其中几轮——导出为结构规范的文档、带图片附件的 ZIP 压缩包，或排版精致的分享长图。

## 如何触发导出

以下 4 种方式都可以打开 <Icon src="/images/icons/export.svg" alt="导出图标" /> **导出对话** 弹窗：

- 按快捷键 <Shortcut combo="ctrl+shift+e" />。
- 点击 **大纲** 标签页工具栏中的 <Icon src="/images/icons/export.svg" alt="导出图标" /> 导出图标。
- 点击浮动快捷按钮中的 <Icon src="/images/icons/tools.svg" alt="工具箱图标" /> **工具箱 → <Icon src="/images/icons/export.svg" alt="导出图标" /> 导出**。
- 在 **对话** 标签页点击任意对话右侧的 <Icon src="/images/icons/more-horizontal.svg" alt="更多菜单图标" /> 菜单（非当前打开的对话会自动打开后导出）。

<Tip>
如果想一键直接下载而不弹窗，可在 **设置 → 功能模块 → 对话 → 导出设置** 中关闭 **导出前显示选项弹窗** 并选好默认格式。如果只需要快速复制，也可以直接按 <Shortcut combo="ctrl+shift+c" />（复制最新回复）或 <Shortcut combo="alt+;" />（复制最后一个代码块）。
</Tip>

## 支持的导出格式

| 格式 | 产物 | 适用场景 |
| --- | --- | --- |
| <Icon src="/images/icons/markdown.svg" alt="Markdown 图标" /><Icon src="/images/icons/zip-file.svg" alt="ZIP 图标" /> **Markdown** | `.md` 或 `.zip` | 导入 Obsidian、Notion、GitHub 或本地知识库。打包方式选 **ZIP 打包** 时，会自动把 `assets/images/`、`assets/files/`、`assets/documents/` 一并打进压缩包。 |
| <Icon src="/images/icons/image-file.svg" alt="图片图标" /> **分享图片** | `.png`、`.jpg` 或分页 `.zip` | 发给同事、贴进文档或发社交平台；内置预览、排版样式、深浅主题与自定义水印。 |
| <Icon src="/images/icons/html-file.svg" alt="HTML 图标" /> **HTML** | `.html` | 独立网页文件，离线直接打开或通过浏览器打印成 PDF。 |
| <Icon src="/images/icons/json-file.svg" alt="JSON 图标" /> **JSON** | `.json` | 包含完整元数据与轮次数组，便于脚本二次处理或长期归档。 |
| <Icon src="/images/icons/txt-file.svg" alt="TXT 图标" /> **纯文本（TXT）** | `.txt` | 去掉 Markdown 语法的轻量纯文本。 |
| <Icon src="/images/icons/copy.svg" alt="复制图标" /><Icon src="/images/icons/copy-outline.svg" alt="复制大纲图标" /> **一键复制到剪贴板** | Markdown / 大纲 | 在导出弹窗里直接点击「复制 Markdown」或「复制大纲」。 |

### Markdown 标题层级自动规范化

导出或复制 Markdown（以及复制包含提问的大纲）时，Ophel 会自动整理标题结构：

- 对话元信息放在简洁的引用块（`> **...**`）里。
- 每一轮对话使用一级标题 `#`。
- 如果某条回复本身包含一级标题 `#`，该消息内的所有标题会自动整体降一级（`H1`–`H5` 变为 `H2`–`H6`，`H6` 转为独立加粗段落），避免导出的文档目录错位。代码块、引用块和列表里的 `#` 不会被误改。

## 导出为分享图片

在导出弹窗（或 **分段导出**）中选择 **图片**，会打开交互式分享图预览界面：

- **排版布局**：
  - **单张长图**（默认）：将选中内容生成为一张完整长图（单画布上限 `16,000 px` 边长 / `16M` 像素）。
  - **自动分页**：在段落或文本行边界智能切分，避开图片、图表、数学公式和表格行（最多 **64 页**）。多张图片支持一键 **下载全部（ZIP）**，单张图片也支持逐张下载、复制（PNG）或新标签查看大图。
- **格式、清晰度与主题**：
  - 格式：**PNG**（默认，单张 PNG 支持直接复制到剪贴板）或 **JPG**。
  - 清晰度：**标准 · 1×** 或 **高清 · 2×**（默认）。
  - 主题：**跟随主题**（默认）、**浅色** 或 **深色**。
- **排版与外观**：
  - 图片宽度：**窄（640 px）**、**标准（800 px，默认）**、**宽（1000 px）**。
  - 正文字号：**小（14 px）**、**标准（16 px，默认）**、**大（18 px）**。
  - 外观风格：**纸面**（默认）、**卡片**、**阴影**。
- **内容开关**：支持分别开关 **显示标题**（可在导出前临时编辑标题并一键还原）、**显示来源**、**显示导出时间**、**包含提问** 与 **品牌署名**（默认均开启）。对话中的图片附件、Mermaid 图表与数学公式会自动渲染内嵌。
- **自定义水印**：默认关闭；最多 120 字；支持 **底部署名** 或 **全图平铺** 两种模式；文字颜色可自动适配或自选（含 5 色预设）；支持调节不透明度（`5%–100%`，默认 `12%`）与字号（`12–64 px`，默认 `24 px`）；平铺模式下还可展开高级设置调整旋转角度（`-90° ~ 90°`，默认 `-30°`）、横纵间距（`20–400 px`，默认 `100 px`）与错行排列（默认开启）。
- **预览操作与快捷键**：支持拖拽平移与缩放（适配 / `50%` / `75%` / `100%`）；按 <Shortcut combo="ctrl+s" /> 下载保存、<Shortcut combo="ctrl+c" /> 复制图片、`0` / `+` / `-` 缩放、`Esc` 关闭。你的排版偏好会自动保存，也支持一键重置与撤销重置。

## 分段导出

在导出弹窗中点击 <Icon src="/images/icons/segmented-export.svg" alt="分段导出图标" /> **分段导出**，可以只挑选需要的对话轮次：

- 支持关键词搜索、手动勾选、**全选** / **反选**，或直接输入序号范围（例如 `1-3, 8`）。
- 支持 **4 种输出模式**：
  1. <Icon src="/images/icons/zip-file.svg" alt="ZIP 图标" /> **ZIP（每段一个 Markdown）**
  2. <Icon src="/images/icons/markdown.svg" alt="Markdown 图标" /> **合并为一个 Markdown**
  3. <Icon src="/images/icons/copy.svg" alt="复制图标" /> **复制为 Markdown**
  4. <Icon src="/images/icons/image-file.svg" alt="图片图标" /> **导出为分享图片**（只把选中的片段送进分享图预览界面）

## 导出设置项

路径：**设置 → 功能模块 → 对话 → 导出设置**

| 设置项 | 可选项 | 默认值 | 所在位置 |
| --- | --- | --- | --- |
| **导出前显示选项弹窗** | 开启 / 关闭 | 开启 | 卡片主区 |
| **默认导出格式** | Markdown / JSON / TXT / HTML / 图片 | Markdown | 卡片主区 |
| **Markdown 打包方式** | 仅 Markdown / ZIP 打包 | 仅 Markdown | 卡片主区 |
| **导出包含思考过程** | 开启 / 关闭 | 开启 | 卡片主区 |
| **导出显示对话序号** | 开启 / 关闭 | 关闭 | 底部 **高级选项** |
| **导出文件名附带时间戳** | 开启 / 关闭 | 关闭 | 底部 **高级选项** |
| **Markdown 分隔符** | 自定义文本 | `---` | 底部 **高级选项** |
| **自定义用户名** | 自定义文本 | *（留空）* | 底部 **高级选项** |
| **自定义模型名** | 自定义文本 | *（留空）* | 底部 **高级选项** |
| **导出风格** | 标准 / 纯净（去除装饰 Emoji） | 标准 | 底部 **高级选项** |
