Ophel 可以导出任何 AI 对话，不仅保留文本，还能保留图片、上传文件、AI 生成的资源、代码产物和推理链——具体取决于平台暴露了什么内容。你可以自由控制输出格式、包含内容和打包方式。

## 如何导出

| 方式 | 说明 |
| --- | --- |
| 浮动快捷按钮 | 点击 <Icon src="/images/icons/tools.svg" alt="工具箱图标" /> 工具箱图标，再点 <Icon src="/images/icons/export.svg" alt="导出图标" /> **导出** |
| 快捷键 | `Ctrl+Shift+E`（Mac：`Command+Shift+E`）导出当前对话为 Markdown |
| 会话标签页 | 点击会话行右侧的 <Icon src="/images/icons/more-horizontal.svg" alt="三个点菜单图标" /> 三点菜单，选择 <Icon src="/images/icons/export.svg" alt="导出图标" /> **导出**，再选择 Markdown、JSON 或 TXT |

触发导出后，会显示全屏进度遮罩，阻止误操作。Ophel 依次完成加载历史、提取内容、打包资源、保存文件、恢复页面状态。

## 导出格式

<Tabs>
  <Tab title="Markdown (.md)">
    保留标题、代码块和图片引用。适合粘贴到笔记工具或文档系统。
  </Tab>
  <Tab title="Markdown zip 资源包 (.zip)">
    与 Markdown 相同的文本输出，额外将所有引用的资源打包到 zip
    归档的子目录中。当对话包含图片、文件或 AI 生成的产物时，选择此模式可以完整保留。
  </Tab>
  <Tab title="JSON (.json)">
    结构化数据，包含所有消息、角色、时间戳和模型信息。适合程序化处理或长期存档。
  </Tab>
  <Tab title="纯文本 (.txt)">
    无格式纯文本，适用于任何文本编辑器。
  </Tab>
</Tabs>

也可以点击 <Icon src="/images/icons/tools.svg" alt="工具箱图标" /> **工具箱** → <Icon src="/images/icons/copy.svg" alt="复制 Markdown 图标" /> **复制 Markdown**，将整个对话以 Markdown 格式复制到剪贴板，无需保存文件。

## 打包模式

在 **设置 → 功能 → 导出 → 打包模式** 中选择 Markdown 导出时如何处理资源文件：

| 模式 | 行为 |
| --- | --- |
| **仅 Markdown** | 导出单个 `.md` 文件，图片和附件以文字引用或外部链接形式出现 |
| **Zip 资源包** | 将 Markdown 文件与所有资源打包为 `.zip` 归档（默认） |

选择 zip 模式后，导出时直接下载压缩包而非独立的 Markdown 文件。

### Zip 包目录结构

```
对话标题.zip
├── 对话标题.md
└── assets/
    ├── images/       ← AI 生成的图片和内嵌图片
    ├── files/        ← 用户上传的附件（PDF、文档等）
    └── documents/    ← 导出的产物（Claude 文档、Gemini Canvas 代码）
```

Markdown 文件内的所有引用使用稳定的相对路径，解压到任何文件夹都能正常显示。

## 平台特有导出说明

### ChatGPT

- **AI 生成图片** — 仅包含图片的 AI 回复会被纳入 Markdown 和 zip 导出。
- **Deep Research 报告** — 导出时包含报告标题和链接；zip 模式下链接文件保留在 `assets/files/` 目录。
- **用户附件** — 用户提示中上传的图片和链接文件在 zip 模式下打包保留。

### Gemini / Gemini Enterprise

- **Canvas 代码产物** — 导出时自动打开 Canvas 产物，切换到代码标签页，将生成的代码纳入 Markdown 输出。
- **Deep Research 导出** — 覆盖自有对话、对话分享页和报告分享页。导出时自动展开关闭的报告面板，完成后恢复原始状态。
- **Deep Research 报告操作** — 当 Deep Research 报告面板打开时，工具栏新增 **复制 Markdown** 和 **下载 Markdown** 按钮，仅导出当前报告，不影响常规对话导出。

### Claude

- **文档产物** — Markdown 文档产物在 zip 包中导出为链接文件，存放在 `assets/documents/` 目录。
- **思维链** — 启用"导出时包含思维链"后，展开的 Claude 思考块会被包含。
- **附件** — 用户提示中的图片和链接文件在 zip 模式下打包保留，文本与产物链接保持原始回复顺序。

### Kimi

- **共享页导出** — 支持从 Kimi 分享页导出对话、提取大纲和滚动导航。
- **思维链** — 启用"导出时包含思维链"后，可见的思考内容会被包含。
- **用户图片** — 上传的图片在 Markdown 和 zip 导出中保留。

### Deep Research 报告导出（Gemini）

Gemini Deep Research 报告的导出独立于常规对话导出：

- 当报告面板打开时，大纲标签页显示 **对话 / 文档** 源切换器，可独立浏览报告大纲。
- 报告面板工具栏提供 **复制 Markdown** 和 **下载 Markdown** 按钮，仅导出报告内容。
- 执行完整对话导出时，Ophel 会自动展开关闭的报告面板，提取内容后恢复原状。

## 导出设置

在 **设置 → 功能 → 导出** 中配置：

| 设置项 | 说明 | 默认值 |
| --- | --- | --- |
| 打包模式 | 仅 Markdown 或 zip 资源包 | Zip 资源包 |
| 默认导出格式 | 点击导出时使用的文件格式 | Markdown |
| 自定义用户名称 | 导出内容中替代"用户"的名称 | （空） |
| 自定义 AI 名称 | 导出内容中替代 AI 名称的文字 | （空） |
| 文件名包含时间戳 | 在导出文件名中添加时间戳后缀 | 关闭 |
| 包含思维链 | 导出支持推理展开的平台的思考过程 | 开启 |
| 图片转 Base64 | 将图片内嵌为 Base64 编码而非链接 | 关闭 |
| 导出文件名模板 | 自定义命名规则（支持 `{title}`、`{date}`） | `{title}` |

## 复制 Markdown

点击 <Icon src="/images/icons/tools.svg" alt="工具箱图标" /> **工具箱** → <Icon src="/images/icons/copy.svg" alt="复制 Markdown 图标" /> **复制 Markdown**，整个对话以 Markdown 格式复制到剪贴板。当你只需要把内容粘贴到笔记、邮件或另一个 AI 对话中时，比导出文件更方便快捷。

## 分享页导出

Ophel 支持从大部分平台的分享页面导出对话。分享页的浏览器标签标题和导出文件名会使用页面标题（当对话标题未在分享页暴露时）。各平台分享页支持情况：

- **Gemini** — 自有对话、对话分享页和报告分享页
- **Kimi** — 分享页对话（含图片和文件标签）
- **Doubao** — `/thread/` 路径下的分享链接
- **Z.ai** — 对话页和分享页
- **ChatGLM** — 分享页（含思考内容）
- **Qwen Studio** — 常规页和分享页（含思考详情）
