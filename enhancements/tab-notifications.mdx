When you're running multiple AI chats across different tabs, keeping track of which tab is which — and knowing when the AI has finished — becomes a real workflow problem. Ophel manages your browser tab titles automatically and can alert you the moment a response is ready, even when you've switched to something else entirely.

## Auto tab renaming

Ophel syncs your browser tab title to the current AI chat, making it easy to identify open sessions from the tab bar.

**Settings → Features → Tab**:

| Setting | Description | Default |
| --- | --- | --- |
| Auto Rename Tab | Sync chat title to the browser tab | On |
| Detection Interval | How often to poll for title changes (1 / 3 / 5 / 10 / 30 / 60 s) | 3 s |
| Title Format | Tab title template using `{status}`, `{title}`, and `{model}` variables | `{status}{title}->{model}` |
| Show Status | Display a generating or completed icon in the tab title (`⏳` / `✅`) | On |
| Only show checkmark when unread | Show `✅` only while the completed reply has not been viewed; hide it after you return to the tab | Off |

The default format produces titles like `⏳ My chat->GPT-4o` while generating and `✅ My chat->GPT-4o` when complete.

The title format editor highlights `{status}`, `{title}`, and `{model}` as token chips and provides buttons to insert them, so you can adjust the template without mistyping a placeholder.

<Tip>
  Enable <Icon src="/images/icons/new-tab.svg" alt="New tab icon" /> **Open New Chat in New Tab** in **Settings → Features → Tab** to show a panel-header button that opens a fresh chat in a new browser tab. Existing chats can be opened in a new tab from the <Icon src="/images/icons/more-horizontal.svg" alt="Chat menu icon" /> chat row menu.
</Tip>

## Generation complete notifications

When the AI finishes a reply in another tab, Ophel can alert you with a desktop notification, a sound, or both.

**Settings → Features → Alerts**:

| Setting | Description | Default |
| --- | --- | --- |
| Desktop Notification | Send a desktop notification when generation completes | Off |
| Notification Sound | Play an audio cue with the notification | On |
| Sound Preset | Choose from built-in sound effects, with preview | softChime |
| Sound Volume | Notification volume (10%–100%) | 50% |
| Play Count | How many times to repeat a short sound (1 / 2 / 3 / 5) | 3 |
| Repeat Interval | Time between each repeat (1 / 2 / 3 / 5 / 10 s) | 2 s |
| Notify When Focused | Also notify when the active tab is already in view | Off |
| Auto Focus the Window | Bring the browser window to the foreground when generation completes | Off |

<Note>
  The first time you enable **Desktop Notification**, the browser will ask
  for the **notifications** permission. Choose Allow. If you previously denied
  it, go to **Settings → Permissions** to grant it.
</Note>

## Privacy mode

If you don't want the tab bar to reveal what you're discussing, privacy mode replaces the browser tab title with custom text of your choosing.

**Settings → Features → Tab**:

| Setting | Description | Default |
| --- | --- | --- |
| Privacy Mode | Replace the tab title with custom text | Off |
| Decoy Title | The text to display instead of the real title | Google |

<Note>
  Privacy mode only affects the browser tab title. It has no effect on
  chat content or anything inside the Ophel panel.
</Note>

## Model lock

Ophel can automatically switch to your preferred model each time you open a particular AI site, so you never have to manually re-select your model after a page load.

This is covered in detail on the [site settings](/customization/site-settings) page.
