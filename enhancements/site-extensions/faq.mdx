---

<AccordionGroup>
  <Accordion title="Why doesn't a Site Pack include a Chats tab or Model Lock?">
    Site Packs use safe declarative JSON rather than custom JavaScript adapters. Features that depend on complex site APIs or account-specific logic—such as sidebar chat syncing, model locking, and multi-account switching—currently stay on built-in adapters.
  </Accordion>

  <Accordion title="Can I bind a local HTTP address (like http://192.168.1.10:3000)?">
    Yes. Custom site bindings under **Settings → Site Packs → Custom sites** accept both `https://` and `http://` exact origins (protocol + host + optional port, no path or wildcard). Only static default URLs inside the public online library require `https://`.
  </Accordion>

  <Accordion title="What happens if I bind the same pack to two self-hosted servers?">
    Ophel isolates site settings, bookmarks, and reading history per pack + origin combination. Changes on your work server never leak into your personal server.
  </Accordion>

  <Accordion title="Can a Site Pack replace one of the 16 built-in sites?">
    Not while the built-in site is enabled—Ophel rejects conflicting packs so nothing fights over the same page. If you first disable a built-in site under **Settings → Site Packs → Built-in sites**, you can install or bind a community pack for that domain.
  </Accordion>

  <Accordion title="How does automatic update work, and can I turn it off?">
    When **Auto-update** is on (default), Ophel checks the signed online index once every 24 hours via a read-only GET request (no cookies or user data sent). You can turn auto-update off anytime under **Settings → Site Packs → Browse & updates** and click **Check updates** manually whenever you want.
  </Accordion>

  <Accordion title="What happens if a website redesigns and a Site Pack stops working?">
    1. Click **Check updates** under **Settings → Site Packs → Browse & updates** to see if a community fix has already shipped.
    2. Check that the pack is still enabled and has browser host permission (especially after restoring a backup).
    3. If it is still broken, report the site name and what stopped working on [GitHub Issues](https://github.com/urzeye/ophel/issues) — or generate an updated pack yourself using the [Authoring guide](/enhancements/site-extensions/authoring).
  </Accordion>

  <Accordion title="What is the 'Built-in Config Patches' section under Browse & updates?">
    Sometimes a built-in platform updates its page markup before a full browser-store review finishes. Ophel can download small signed selector patches for built-in sites automatically. The collapsed **Built-in Config Patches** section lets advanced users inspect, ignore, reset, or import local test patches.
  </Accordion>

  <Accordion title="Do I lose my settings if I uninstall a Site Pack?">
    No. Uninstalling removes the pack and its custom origin bindings, but your saved layout settings and local data stay intact if you reinstall later.
  </Accordion>
</AccordionGroup>
