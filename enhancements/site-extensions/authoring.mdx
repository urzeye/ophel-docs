<Note>
This guide is for **Site Pack authors and contributors**. For end-user installation instructions, see [Install & Manage](/enhancements/site-extensions/installation).
</Note>

Site Packs are pure declarative JSON files stored in [`registry/sites/`](https://github.com/urzeye/ophel/tree/main/registry/sites) in the main `ophel` repository.

## Start from an example

Copy [`registry/examples/site-pack.example.json`](https://github.com/urzeye/ophel/blob/main/registry/examples/site-pack.example.json) or adapt a similar existing pack such as [`registry/sites/duck-ai.json`](https://github.com/urzeye/ophel/blob/main/registry/sites/duck-ai.json).

### Minimal valid manifest structure

```json
{
  "schemaVersion": 1,
  "id": "example-chat",
  "version": 1,
  "minAppVersion": "1.2.5",
  "name": "Example Chat",
  "nameI18n": {
    "en": "Example Chat",
    "zh-CN": "示例对话"
  },
  "description": "Outline, export, prompts, and layout controls for Example Chat.",
  "matches": ["https://chat.example.com/*"],
  "capabilities": ["outline", "outline-user-queries", "export-basic", "prompt-insert"],
  "selectors": {
    "textarea": ["textarea[data-testid='prompt-input']"],
    "responseContainer": "main .messages",
    "userQuery": "[data-role='user']",
    "assistantResponse": "[data-role='assistant']",
    "scrollContainer": ["main"]
  },
  "input": {
    "mode": "textarea",
    "submitKey": "Enter"
  },
  "export": {
    "userQuerySelector": "[data-role='user']",
    "assistantResponseSelector": "[data-role='assistant']",
    "turnSelector": null,
    "useShadowDOM": false
  }
}
```

## Schema & security rules

The validator (`src/adapters/declarative/validate.ts` and `registry/schema/site-pack.schema.json`) enforces these constraints:

- **`schemaVersion`**: Must be `1`.
- **No `$schema` property**: Omit `$schema` from the JSON file (rejected by strict schema validation).
- **`id`**: Lowercase alphanumeric + hyphens (`^[a-z0-9-]{2,40}$`), unique across all built-in sites and community packs.
- **`version`**: Positive integer; increment monotonically on every published update.
- **`minAppVersion`**: Valid SemVer string matching the minimum Ophel version that supports every field you use.
- **`matches`**: Up to **10** `https://` match patterns for registry packs. Leave as `[]` for pure self-hosted packs (users bind their own `http://` or `https://` origin after installing).
- **`selectors`**: Required top-level object. Prefer stable `data-*`, `aria-*`, semantic HTML tags, or fixed IDs over hashed bundler class names or single-language text.
- **Localization**: Provide `nameI18n` and `descriptionI18n` covering Ophel's 11 UI locales (`zh-CN`, `zh-TW`, `en`, `ja`, `ko`, `it`, `de`, `es`, `fr`, `pt-BR`, `ru`).
- **Size & safety limits**:
  - Serialized JSON must be **≤ 64 KiB**.
  - Array fields are capped at **50 items**.
  - Regex patterns (such as `session.idFromPathRegex`) are checked by `safe-regex2` to prevent catastrophic backtracking.
  - Same-origin path templates (such as `session.newTabPath`) must start with a single `/`.

See [Capabilities Reference](/enhancements/site-extensions/capabilities) for the exact fields required by each capability and `themeSync`.

## Test locally, validate, and contribute

<Steps>
  <Step title="Test directly in Ophel">
    Import your draft `.json` file under **Settings → Site Packs → Browse & updates → Import pack from file**, grant access for the target domain, and verify every declared capability on a live conversation.
  </Step>
  <Step title="Run repository validation">
    Clone [urzeye/ophel](https://github.com/urzeye/ophel), save your manifest as `registry/sites/<id>.json`, and run:

    ```bash
    pnpm registry:validate       # Validate all packs, schemas, regex safety, and match conflicts
    pnpm registry:build          # Build local unsigned dist for testing
    pnpm registry:build:signed   # Build signed dist (used by release automation)
    ```
  </Step>
  <Step title="Open a pull request">
    Review [`registry/README.md`](https://github.com/urzeye/ophel/blob/main/registry/README.md), [`docs/developer/conventions/site-pack.md`](https://github.com/urzeye/ophel/blob/main/docs/developer/conventions/site-pack.md), and the [Site Pack PR template](https://github.com/urzeye/ophel/blob/main/.github/PULL_REQUEST_TEMPLATE/site-pack.md), then submit your PR.
  </Step>
</Steps>
