<Note>
This page is a technical reference for **Site Pack authors and contributors**. If you only want to install and use existing Site Packs, see [Site Packs Overview](/enhancements/site-extensions) and [Install & Manage](/enhancements/site-extensions/installation).
</Note>

Every Site Pack declares a `capabilities` array that tells Ophel's UI and runtime which features the target site supports. The validator enforces that every declared capability is backed by its required configuration fields; controls for undeclared capabilities are hidden automatically in Ophel's UI.

The authoritative definitions live in `src/adapters/feature-capabilities.ts`, `src/adapters/declarative/validate.ts`, and `registry/schema/site-pack.schema.json` in the [ophel repository](https://github.com/urzeye/ophel).

## Capability catalog (15 IDs)

| Capability ID | What it enables | Required config fields in a Site Pack |
| --- | --- | --- |
| `outline` | Heading outline tree (`H1`–`H6`) | `selectors.responseContainer` (or `selectors.assistantResponse` / `selectors.outlineHeadings`) |
| `outline-user-queries` | User prompts inside the outline | `selectors.userQuery` |
| `document-outline` | Separate document/artifact outline source | Document outline source selectors |
| `conversation-list` | Sidebar chat history sync | Conversation list selectors *(currently used by built-in adapters)* |
| `export-basic` | Basic Markdown / HTML / JSON / TXT / Image export | `export` (`userQuerySelector` and `assistantResponseSelector`) |
| `model-lock` | Automatic model locking | Model selector config *(currently used by built-in adapters)* |
| `generation-detect` | Generating/idle state detection for tab status, alerts, and queue | `generation.stopButton` / `generation.loadingIndicator` and/or `networkMonitor` |
| `new-chat` | New chat shortcut & button | `selectors.newChatButton` and/or `session.newTabPath` |
| `stop-generation` | Stop generation shortcut | `generation.stopButton` |
| `width` | Page width & user message width sliders | `width` selectors (`selectors`, `userQuerySelectors`) |
| `panel-avoidance` | Smart Avoidance around the Floating panel | `panelAvoidance` container configuration |
| `zen` | Zen Mode (hide navigation chrome) | `zenMode.hide` selectors |
| `clean` | Clean Mode (hide disclaimers/promos) | `cleanMode.hide` selectors |
| `prompt-insert` | Insert prompts from Prompt Library / Queue / Chains | `selectors.textarea` and `input` (`mode`: `textarea` or `contenteditable`) |
| `reading-history` | Save and restore scroll position per thread | `session.idFromPathRegex` + `selectors.scrollContainer` |

## Additional top-level behavior fields

Some behaviors are configured directly at the top level rather than as capability IDs:

### `themeSync` (host page theme synchronization)

There is no `theme-sync` capability ID. Add a `themeSync` object to keep the host site's light/dark mode in sync with Ophel:

- **`storageType`**: `"localStorage"` (default) or `"cookie"` (for cookie-driven sites such as Perplexity; cookie mode writes flat values and deletes the cookie on `system` when `values.system` is omitted).
- **`storageKey`**: Required key name in `localStorage` or cookie.
- **`values`**: Required `{ dark, light, system? }` string mapping.
- **`valuePath`** / **`valueFormat`**: For `localStorage`, use `valuePath` (dot-separated JSON path such as `"theme"` or `"appearance.mode"`) for nested JSON objects, or `valueFormat` (`"raw"` or `"json"`) for flat values. `valuePath` and `valueFormat: "json"` are mutually exclusive.
- **`timestampPath` / `staticFields`**: Optional fields used together with `valuePath` when the site expects a timestamp or fixed keys inside the JSON payload.
- **`extraKeys`**: Optional additional flat `localStorage` keys to update alongside `storageKey`.
- **`domSync`**: Optional array of `{ selector, attributes?, classes? }` rules to update `data-*` attributes (strictly `data-` prefixed) and `{mode}` class templates (for example `["{mode}", "vscode-{mode}"]`) on matched elements such as `html` or `body`.

### Other top-level flags and `traits`

- **`outlineReverse: true`**: Use when the site renders messages in reverse DOM order (for example, `flex-direction: column-reverse`).
- **`scrollPinRelease: true`**: Dispatches a zero-delta wheel event after outline jumps on sites that pin scroll to the bottom until user wheel input.
- **`traits.minimalEnhancements: true`**: Runs Ophel in minimal mode (Theme + Panel Avoidance only), as used by Muse.
- **`traits.periodicOutlineRefresh: true`**: Enables periodic outline refreshes for dynamic layouts that do not emit reliable mutations.
- **`mermaidSupport`**: Set `"fallback"` if the site lacks native Mermaid rendering.
- **`quickQuote`**: Set `"disabled"` if Ophel's selection toolbar conflicts with the host site's UI.

## Example: Duck.ai capability set

```json
{
  "capabilities": [
    "outline",
    "outline-user-queries",
    "export-basic",
    "generation-detect",
    "new-chat",
    "stop-generation",
    "width",
    "zen",
    "prompt-insert"
  ]
}
```

See the full manifest in [`registry/sites/duck-ai.json`](https://github.com/urzeye/ophel/blob/main/registry/sites/duck-ai.json).
