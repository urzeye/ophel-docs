Ophel enhances how messages, math formulas, tables, and diagrams behave inside AI chats. All global content options live under **Settings → Features → Content**.

## Mermaid diagram rendering

Some AI sites output Mermaid diagrams only as plain code blocks. When **Assistant Mermaid Render** is enabled (default **Off**), Ophel renders Mermaid code blocks in AI replies into interactive SVG diagrams whenever the host site does not render them natively.

- Zoom smoothly between **50% and 300%**.
- Open diagrams full-screen for inspection.
- Export diagrams as **2× PNG** images.

## User prompt Markdown rendering

Most chat platforms display your own sent messages as plain unformatted text. With **User Query Markdown Rendering** enabled (default **On**), Ophel formats headings, lists, math formulas, and fenced code blocks (with one-click copy buttons) right inside your message bubbles.

## Formula source copy

When an AI platform renders math formulas, **Double-click to copy formula** (default **On**) lets you double-click any rendered formula to copy its underlying source straight to your clipboard.

Expand **Advanced options** at the bottom of the Content card to configure:

- **Formula copy format**: **LaTeX** (default) or **MathML**.
- **Keep delimiters when copying** (default **On**): Wraps copied LaTeX in `$ ... $` for inline formulas or `$$ ... $$` for display formulas.

## Markdown table copy

With **Table Copy Markdown** enabled (default **On**), Ophel adds a copy button to the top-right corner of rendered tables in AI replies so you can copy them cleanly as Markdown tables.

## Settings summary

Open **Settings → Features → Content**:

| Setting | Options | Default | Location |
| --- | --- | --- | --- |
| **Assistant Mermaid Render** | On / Off | Off | Main card |
| **User Query Markdown Rendering** | On / Off | On | Main card |
| **Double-click to copy formula** | On / Off | On | Main card |
| **Table Copy Markdown** | On / Off | On | Main card |
| **Formula copy format** | LaTeX / MathML | LaTeX | **Advanced options** |
| **Keep delimiters when copying** | On / Off | On | **Advanced options** |

## Related site-specific enhancements

Site-level fixes and optimizations live under **Settings → Site Settings** instead of global Content settings:

- **Markdown bold fix** (Gemini, AI Studio, ChatGPT)
- **Generated-image watermark removal** (Gemini) & **background watermark blocker** (AI Studio)
- **Long-chat rendering optimizations** (ChatGPT)

See [Site Settings](/customization/site-settings) for details, or [Chat Export](/features/export) for exporting conversations and assets.
