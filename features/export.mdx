Ophel lets you export an entire conversation—or just the turns you pick—into clean documents, attachment ZIP archives, or styled shareable images.

## How to export

Open the **Export Chat** dialog in any of four ways:

- Press <Shortcut combo="ctrl+shift+e" />.
- Click the **Export** icon in the **Outline** tab toolbar.
- Click **Toolbox → Export** in the floating quick buttons.
- Open the `⋯` menu on any chat in the **Chats** tab (for non-open chats, Ophel opens the thread and exports it).

<Tip>
If you prefer one-click downloads without the dialog, turn off **Show Export Options Dialog** under **Settings → Features → Chats → Export Settings** and set your **Default Export Format**. For quick copying without opening the dialog, use <Shortcut combo="ctrl+shift+c" /> (copy latest reply) or <Shortcut combo="alt+;" /> (copy last code block).
</Tip>

## Supported export formats

| Format | Output | Best for |
| --- | --- | --- |
| **Markdown** | `.md` or `.zip` | Obsidian, Notion, GitHub, and personal knowledge bases. When packaging is set to **ZIP**, Ophel bundles `assets/images/`, `assets/files/`, and `assets/documents/` alongside the Markdown file. |
| **Shareable Image** | `.png`, `.jpg`, or `.zip` | Sharing clean conversations on social media, docs, or chat apps, with full preview, layout, theme, and watermark controls. |
| **HTML** | `.html` | Standalone web page you can open offline or print to PDF in any browser. |
| **JSON** | `.json` | Structured metadata + turn array for scripts, archiving, or downstream processing. |
| **Plain Text** | `.txt` | Lightweight stripped text without Markdown formatting. |
| **Clipboard actions** | Markdown / Outline | Copy the entire chat as Markdown or copy just the heading outline straight from the export dialog. |

### Normalized Markdown headings

When exporting or copying Markdown (and when copying outlines with questions enabled), Ophel automatically normalizes heading levels:

- Conversation metadata is placed in a clean quote block (`> **...**`).
- Each turn uses a top-level `#` heading.
- If a message itself contains top-level `#` headings, Ophel shifts all headings inside that message down by one level (`H1`–`H5` → `H2`–`H6`, and `H6` becomes a bold paragraph) so your exported document keeps a valid nested outline. Headings inside fenced code blocks, indented code blocks, quotes, or lists are left untouched.

## Export as shareable image

Choose **Image** in the Export dialog (or in **Segmented Export**) to open the interactive image preview studio:

- **Layout**:
  - **Single long image** (default): Renders the full selection into one tall image (up to `16,000 px` height / `16M` pixels).
  - **Split automatically**: Splits long chats cleanly at block or text-line boundaries—avoiding cuts through images, diagrams, math formulas, or table rows (up to **64 pages**). Multi-page exports download as a single `.zip`, and each page can also be downloaded, copied (PNG), or opened full-size individually.
- **Format, resolution, and theme**:
  - Format: **PNG** (default; supports direct clipboard copy for single images) or **JPG**.
  - Resolution: **Standard · 1×** or **High · 2×** (default).
  - Theme: **Follow theme** (default), **Light**, or **Dark**.
- **Layout and appearance**:
  - Width: **640 px** (Narrow), **800 px** (default), or **1000 px** (Wide).
  - Font size: **14 px** (Small), **16 px** (Medium, default), or **18 px** (Large).
  - Appearance: **Paper** (default), **Card**, or **Shadow**.
- **Content controls**: Toggle **Show title** (with inline title editing and one-click reset), **Show source**, **Show export time**, **Include questions**, and **Brand signature** (all default **On**). Embedded images, Mermaid diagrams, and math formulas render automatically.
- **Custom watermark**: Off by default; supports up to 120 characters, **Footer** or **Tile** mode, automatic or custom color (with 5 presets), opacity (`5%–100%`, default `12%`), font size (`12–64 px`, default `24 px`), plus tile rotation (`-90°` to `90°`, default `-30°`), X/Y spacing (`20–400 px`, default `100 px`), and staggered rows (default **On**).
- **Preview controls & shortcuts**: Pan and zoom (`Fit`, `50%`, `75%`, `100%`); press <Shortcut combo="ctrl+s" /> to save, <Shortcut combo="ctrl+c" /> to copy, `0` / `+` / `-` to zoom, and `Esc` to close. Preferences are remembered automatically, with a reset button and undo.

## Segmented export

Click **Segmented Export** in the Export dialog to pick only the turns you want:

- Filter turns by keyword, check individual turns, use **Select all** / **Invert**, or enter ranges such as `1-3, 8`.
- Choose from **4 output modes**:
  1. **ZIP (one Markdown per segment)**
  2. **Merge into one Markdown**
  3. **Copy as Markdown**
  4. **Export as image** (opens the shareable image studio with only your selected turns)

## Export settings

Open **Settings → Features → Chats → Export Settings**:

| Setting | Options | Default | Location |
| --- | --- | --- | --- |
| **Show Export Options Dialog** | On / Off | On | Main card |
| **Default Export Format** | Markdown / JSON / TXT / HTML / Image | Markdown | Main card |
| **Markdown Export Method** | Markdown only / ZIP package | Markdown only | Main card |
| **Include Thoughts in Export** | On / Off | On | Main card |
| **Show Turn Numbers in Export** | On / Off | Off | **Advanced options** |
| **Add Timestamp to Filename** | On / Off | Off | **Advanced options** |
| **Markdown Divider** | Custom text | `---` | **Advanced options** |
| **Custom User Name** | Custom text | *(empty)* | **Advanced options** |
| **Custom AI Name** | Custom text | *(empty)* | **Advanced options** |
| **Export Style** | Standard / Clean (no decorative emoji) | Standard | **Advanced options** |
