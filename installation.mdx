Ophel Atlas is available as a browser extension for Chrome-based browsers and Firefox, and as a userscript for Tampermonkey. The browser extension is recommended — it offers a fuller feature set, better compatibility, and does not require developer mode after the initial install.

<Tip>
  Use the browser extension version whenever possible. The userscript version
  has feature limitations compared to the extension and may have lower
  compatibility on some platforms.
</Tip>

## Install from a store

<Tabs>
  <Tab title="Chrome">
    Install directly from the Chrome Web Store — no developer mode required.

    <Steps>
      <Step title="Open the Chrome Web Store listing">
        Go to the [Ophel Atlas listing on the Chrome Web Store](https://chromewebstore.google.com/detail/ophel-ai-%E5%AF%B9%E8%AF%9D%E5%A2%9E%E5%BC%BA%E5%B7%A5%E5%85%B7/lpcohdfbomkgepfladogodgeoppclakd).
      </Step>
      <Step title="Click Add to Chrome">
        Click **Add to Chrome** and confirm the permissions prompt.
      </Step>
      <Step title="Open a supported AI site">
        Navigate to any [supported platform](#supported-platforms) — for example, [chatgpt.com](https://chatgpt.com) or [claude.ai](https://claude.ai). The Ophel panel appears automatically on the right side of the page.
      </Step>
    </Steps>

  </Tab>
  <Tab title="Edge Add-ons">
    Install directly from the Microsoft Edge Add-ons store.

    <Steps>
      <Step title="Open the Edge Add-ons listing">
        Go to the [Ophel Atlas listing on the Microsoft Edge Add-ons store](https://microsoftedge.microsoft.com/addons/detail/ophel-atlas-ai-chat-navi/ffpenkdeifijngifjmbbpijfpdhlolga).
      </Step>
      <Step title="Click Get">
        Click **Get** and confirm the permissions prompt.
      </Step>
      <Step title="Open a supported AI site">
        Navigate to any [supported platform](#supported-platforms) — for example, [chatgpt.com](https://chatgpt.com) or [claude.ai](https://claude.ai). The Ophel panel appears automatically on the right side of the page.
      </Step>
    </Steps>

  </Tab>
  <Tab title="Firefox">
    Install from the Firefox Add-ons store for a persistent, auto-updating installation.

    <Steps>
      <Step title="Open the Firefox Add-ons listing">
        Go to the [Ophel AI Chat Enhancer listing on Firefox Add-ons](https://addons.mozilla.org/zh-CN/firefox/addon/ophel-ai-chat-enhancer/).
      </Step>
      <Step title="Click Add to Firefox">
        Click **Add to Firefox** and confirm the permissions prompt.
      </Step>
      <Step title="Open a supported AI site">
        Navigate to any [supported platform](#supported-platforms). The Ophel panel appears automatically.
      </Step>
    </Steps>

  </Tab>
  <Tab title="Userscript (Tampermonkey)">
    Use this method if you cannot install browser extensions, or if you prefer the Tampermonkey workflow.

    <Warning>
      The userscript version has feature limitations compared to the browser extension. Install the extension version when possible.
    </Warning>

    <Steps>
      <Step title="Install Tampermonkey">
        If you do not already have it, install [Tampermonkey](https://www.tampermonkey.net/) for your browser.
      </Step>
      <Step title="Open the Greasy Fork listing">
        Go to the [Ophel AI Chat Page Enhancer on Greasy Fork](https://greasyfork.org/zh-CN/scripts/563646-ophel-ai-chat-page-enhancer).
      </Step>
      <Step title="Click Install this script">
        Click **Install this script**. Tampermonkey opens a confirmation dialog — click **Install**.
      </Step>
      <Step title="Open a supported AI site">
        Navigate to any [supported platform](#supported-platforms). The Ophel panel appears automatically.
      </Step>
    </Steps>

  </Tab>
</Tabs>

## Manual sideload from GitHub Releases

Use this method if you want to install a specific version, test a pre-release build, or install without a store.

<Tabs>
  <Tab title="Chrome / Edge (manual)">
    <Steps>
      <Step title="Download the release archive">
        Go to [GitHub Releases](https://github.com/urzeye/ophel/releases) and download the latest `ophel-vX.X.X-chrome.zip`.
      </Step>
      <Step title="Unzip the archive">
        Extract the zip to a permanent folder on your computer. Do not delete the folder after loading — the browser loads the extension from it every time.
      </Step>
      <Step title="Open the extensions page">
        In Chrome: navigate to `chrome://extensions`. In Edge: navigate to `edge://extensions`.
      </Step>
      <Step title="Enable Developer mode">
        Toggle **Developer mode** on (top-right corner of the extensions page).
      </Step>
      <Step title="Load the unpacked folder">
        Click **Load unpacked** and select the folder you extracted in step 2.
      </Step>
    </Steps>
  </Tab>
  <Tab title="Firefox (manual)">
    <Warning>
      Firefox only allows temporary add-on loading through the debugging interface. The add-on is removed when you restart the browser, so you must reload it after each restart. For a persistent install, use the [Firefox Add-ons store](#install-from-a-store) tab above.
    </Warning>

    <Steps>
      <Step title="Download the release archive">
        Go to [GitHub Releases](https://github.com/urzeye/ophel/releases) and download the latest `ophel-vX.X.X-firefox.zip`.
      </Step>
      <Step title="Open the Firefox debugging page">
        Navigate to `about:debugging#/runtime/this-firefox`.
      </Step>
      <Step title="Load the temporary add-on">
        Click **Load Temporary Add-on** and select the downloaded zip file. You do not need to extract it.
      </Step>
    </Steps>

  </Tab>
  <Tab title="Userscript (manual)">
    <Steps>
      <Step title="Install Tampermonkey">
        If you do not already have it, install [Tampermonkey](https://www.tampermonkey.net/) for your browser.
      </Step>
      <Step title="Download the userscript file">
        Go to [GitHub Releases](https://github.com/urzeye/ophel/releases) and download the latest `.user.js` file.
      </Step>
      <Step title="Install the script">
        Drag the `.user.js` file into your browser window, or open the Tampermonkey dashboard and use **Import from file**. Confirm the install when prompted.
      </Step>
    </Steps>
  </Tab>
</Tabs>

## Supported platforms

After installation, Ophel activates automatically on all 15 of the following platforms:

| Platform              | URL                    |
| --------------------- | ---------------------- |
| **ChatGPT**           | chatgpt.com            |
| **Gemini**            | gemini.google.com      |
| **Gemini Enterprise** | business.gemini.google |
| **AI Studio**         | aistudio.google.com    |
| **Claude**            | claude.ai              |
| **Grok**              | grok.com               |
| **DeepSeek**          | chat.deepseek.com      |
| **Doubao**            | www.doubao.com         |
| **Kimi**              | www.kimi.com           |
| **Qwen Studio**       | chat.qwen.ai           |
| **Qianwen**           | www.qianwen.com        |
| **Yuanbao**           | yuanbao.tencent.com    |
| **Z.ai**              | chat.z.ai              |
| **ChatGLM**           | chatglm.cn             |
| **ima**               | ima.qq.com             |

<Note>
  Support for each platform depends on the site's page structure. If a platform
  update changes the page layout, Ophel may require an update before it works
  correctly again. Check [GitHub Issues](https://github.com/urzeye/ophel/issues)
  for known compatibility problems.
</Note>
