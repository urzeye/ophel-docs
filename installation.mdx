Ophel Atlas is distributed as a browser extension and as a userscript built from the same codebase.

<Tip>
Browser extensions (Chrome, Edge, Firefox) give you the complete feature set, including optional permission controls, browser-level shortcuts, and Claude browser cookie import. Use the userscript if you cannot install extensions or run another browser with Tampermonkey, Violentmonkey, or ScriptCat.
</Tip>

## Platform capability comparison

Use this table to see what differs across runtimes before choosing how to install:

| Capability | <Icon src="/images/icons/chrome.svg" alt="Chrome icon" /><Icon src="/images/icons/edge.svg" alt="Edge icon" /> Chrome / Edge | <Icon src="/images/icons/firefox.svg" alt="Firefox icon" /> Firefox | <Icon src="/images/icons/safari.svg" alt="Safari icon" /> Safari (macOS, Experimental) | <Icon src="/images/icons/tampermonkey.svg" alt="Tampermonkey icon" /> Userscript |
| --- | --- | --- | --- | --- |
| Core features (Outline, Chats, Prompts, Export, Global Search, Themes, Layout) | Full | Full | Full | Full |
| Site Packs & custom self-hosted domains | Full (per-origin permission prompt) | Full (per-origin permission prompt) | Full (managed in Safari Settings) | Full (no browser prompt; matched by script whitelist) |
| WebDAV manual & scheduled automatic backups | Full (`chrome.alarms` background schedule) | Full (`chrome.alarms` background schedule) | Full (grant target server host in Safari Settings) | Full (automatic backups run while any supported tab is open) |
| Desktop notifications on reply completion | Optional (`notifications` permission; default off) | Optional (`notifications` permission; default off) | Not supported (sound & tab title status still work) | Supported via `GM_notification` (default on) |
| Auto-focus window when generation finishes | Supported | Supported | Not supported | Partial (`window.focus()` only; cannot unminimize windows) |
| Gemini generated-image watermark removal | Optional (`<all_urls>` permission) | Optional (`<all_urls>` permission) | Not supported | Supported |
| Claude Session Key management | Full (including import from browser cookies & cross-tab generating check) | Full (including import from browser cookies & cross-tab generating check) | Full (manual/JSON keys; cookies permission supported) | Partial (manual/JSON keys & switch on `claude.ai`; no browser cookie import or cross-tab check) |
| Global browser shortcut (<Shortcut combo="alt+o" />) | Supported | Supported | Supported | Not supported (all in-page shortcuts still work) |
| AI Studio preload tweaks (early sidebar collapse & background watermark blocker) | Supported | Supported | Supported | Not available (no userscript preload entry) |
| Persistence across restarts | Permanent | Permanent (from AMO) | **Temporary (24 hours or until Safari quits)** | Permanent |

## Install from a store or script directory

<Tabs>
  <Tab title="Chrome / Chromium">
    <Steps>
      <Step title="Open the Chrome Web Store">
        Visit the [Ophel Atlas Chrome Web Store page](https://chromewebstore.google.com/detail/ai-chat-organizer-outline/lpcohdfbomkgepfladogodgeoppclakd).
      </Step>
      <Step title="Add the extension">
        Click **Add to Chrome** (or **Add to Brave / Arc / Vivaldi**) and confirm the prompt.
      </Step>
      <Step title="Open a supported AI site">
        Visit any [supported platform](/index#supported-platforms). Refresh the tab if it was already open.
      </Step>
    </Steps>
  </Tab>

  <Tab title="Microsoft Edge">
    <Steps>
      <Step title="Open Edge Add-ons">
        Visit the [Ophel Atlas Microsoft Edge Add-ons page](https://microsoftedge.microsoft.com/addons/detail/ophel-atlas-ai-chat-navi/ffpenkdeifijngifjmbbpijfpdhlolga).
      </Step>
      <Step title="Install">
        Click **Get** and then **Add extension**.
      </Step>
      <Step title="Open a supported AI site">
        Open or refresh any [supported platform](/index#supported-platforms).
      </Step>
    </Steps>
  </Tab>

  <Tab title="Firefox">
    <Steps>
      <Step title="Open Firefox Add-ons">
        Visit the [Ophel Atlas Firefox Add-ons page](https://addons.mozilla.org/firefox/addon/ophel-ai-chat-enhancer/) (requires Firefox 109 or newer).
      </Step>
      <Step title="Add to Firefox">
        Click **Add to Firefox** and confirm the permission dialog.
      </Step>
      <Step title="Open a supported AI site">
        Open or refresh any [supported platform](/index#supported-platforms).
      </Step>
    </Steps>
  </Tab>

  <Tab title="Userscript (Greasy Fork / ScriptCat)">
    <Steps>
      <Step title="Install a userscript manager">
        Install [Tampermonkey](https://www.tampermonkey.net/), [Violentmonkey](https://violentmonkey.github.io/), or [ScriptCat](https://docs.scriptcat.org/) in your browser.
      </Step>
      <Step title="Install the Ophel script">
        Open [Greasy Fork](https://greasyfork.org/scripts/563646-ophel-ai-chat-page-enhancer) or [ScriptCat](https://scriptcat.org/script-show-page/6519), click **Install this script**, and confirm inside your script manager.
      </Step>
      <Step title="Open a supported AI site">
        Open or refresh any [supported platform](/index#supported-platforms).
      </Step>
    </Steps>

    <Note>
    The userscript loads version-pinned helper bundles and assets via `@require` and `@resource` with `#sha256=` integrity checks, and exits immediately on pages outside your enabled sites.
    </Note>
  </Tab>
</Tabs>

## Manual install from GitHub Releases

Download packages directly from [GitHub Releases](https://github.com/urzeye/ophel/releases) when you want to test a fresh release before store review finishes, install offline, or try the experimental macOS Safari build.

<Warning>
Do **not** manually sideload `*-cws-upload.zip` or `*-edge-addons-upload.zip`. Those archives are generated specifically for store uploads and strip manifest metadata needed for local loading.
</Warning>

<Tabs>
  <Tab title="Chrome / Edge">
    <Steps>
      <Step title="Download and unzip">
        Download `ophel-atlas-vX.X.X-chrome.zip` from GitHub Releases and extract it into a permanent folder (removing the folder breaks the extension).
      </Step>
      <Step title="Open the extensions page">
        Go to `chrome://extensions` (Chrome) or `edge://extensions` (Edge) and turn on **Developer mode**.
      </Step>
      <Step title="Load unpacked">
        Click **Load unpacked** and select the extracted folder containing `manifest.json`.
      </Step>
    </Steps>
  </Tab>

  <Tab title="Firefox">
    <Warning>
    GitHub Releases distributes an unsigned ZIP (`ophel-atlas-vX.X.X-firefox.zip`). Loading it through `about:debugging` is temporary and Firefox removes it when the browser restarts. For permanent installation, use [Firefox Add-ons (AMO)](https://addons.mozilla.org/firefox/addon/ophel-ai-chat-enhancer/).
    </Warning>

    <Steps>
      <Step title="Download and unzip">
        Download `ophel-atlas-vX.X.X-firefox.zip` and extract it.
      </Step>
      <Step title="Open about:debugging">
        Navigate to `about:debugging#/runtime/this-firefox`.
      </Step>
      <Step title="Load temporary add-on">
        Click **Load Temporary Add-on…** and select `manifest.json` inside the extracted folder.
      </Step>
    </Steps>
  </Tab>

  <Tab title="Safari (macOS, Experimental)">
    <Warning>
    Desktop Safari support is **experimental** and only runs as a temporary extension on macOS. Safari automatically removes temporary extensions after **24 hours** or whenever you quit Safari. There is currently no signed Safari App Store release or iOS Safari build.
    </Warning>

    <Steps>
      <Step title="Download and unzip">
        Download `ophel-atlas-vX.X.X-safari.zip` from GitHub Releases and extract it. No Xcode or paid Apple Developer account is required.
      </Step>
      <Step title="Enable Safari developer features">
        Open **Safari → Settings → Advanced** and check **Show features for web developers**.
      </Step>
      <Step title="Add temporary extension">
        Go to **Safari → Settings → Developer** (or the **Develop** menu), choose **Add Temporary Extension…**, and pick the extracted folder containing `manifest.json`.
      </Step>
      <Step title="Grant website access">
        Open **Safari → Settings → Extensions**, enable **Ophel Atlas**, and allow access on the AI sites you use.
      </Step>
    </Steps>
  </Tab>

  <Tab title="Userscript">
    <Steps>
      <Step title="Download the script">
        Download `ophel-atlas-vX.X.X.user.js` from GitHub Releases.
      </Step>
      <Step title="Import into your script manager">
        Drag the `.user.js` file into your browser window, or open your script manager dashboard and import it manually.
      </Step>
    </Steps>
  </Tab>
</Tabs>
