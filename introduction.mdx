Long AI sessions get hard to read and harder to find later. Most chat sites give you one flat, scrolling column with little or no way to jump between sections, group threads by topic, or reuse prompt workflows across tools.

Ophel Atlas runs inside your AI chat pages and adds the same structured workspace across platforms: a live outline, folder-and-tag organization, reusable prompts, flexible exports, and reading controls.

## Core capabilities

  <Card title="Smart Outline" icon="/images/icons/outline.svg" href="/features/outline">

  </Card>
  <Card title="Chat Management & Export" icon="/images/icons/folder.svg" href="/features/conversations">

  </Card>
  <Card title="Prompt Library, Queues & Chains" icon="/images/icons/prompt.svg" href="/features/prompts">

## Supported platforms

Ophel ships with **16 built-in site adapters**. Feature availability depends on what each platform exposes (for example, sites without a sidebar chat list do not show the **Chats** tab).

| Platform | Domains | Notes |
| --- | --- | --- |
| **ChatGPT** | `chatgpt.com` *(legacy `chat.openai.com` redirects here)* | Full features; API-first export; per-workspace chat isolation; long-chat performance options |
| **Gemini** | `gemini.google.com` | Full features; document outline (Deep Research / Canvas); image watermark removal; auto-hide input |
| **Claude** | `claude.ai` | Full features; document outline (Artifacts); API-first outline & export; per-organization isolation; Session Key switcher |
| **Google AI Studio** | `aistudio.google.com` | Full features; API-first outline & export; sidebar/panel collapse and background watermark options |
| **Grok** | `grok.com` | API-first outline, chat list & export; no Clean Mode |
| **Gemini Notebook** | `notebook.google.com` | Minimal enhancement mode: 3-source outline (Sources / Chat / Studio), prompt insert, panel avoidance, DOM snapshot export; no Chats tab or model lock |
| **Gemini Enterprise** | `business.gemini.google` | Disabled by default for new installs; enable in **Settings → Site Packs → Built-in sites** |
| **DeepSeek** | `chat.deepseek.com` | API-first outline & export; no model lock |
| **Doubao / Dola** | `www.doubao.com`, `www.dola.com` | Same built-in adapter; displays as **Dola** on `dola.com`; local chats/bookmarks isolated per domain while sharing settings |
| **Kimi** | `www.kimi.com`, `www.kimi.ai` | Full features; local chats/bookmarks isolated per domain while sharing settings |
| **Qwen Studio** | `chat.qwen.ai` | API-first outline, chat list & export |
| **Qianwen** | `www.qianwen.com`, `qianwen.com` | No sidebar chat list sync (Chats tab hidden) |
| **Yuanbao** | `yuanbao.tencent.com` | Full features; Monaco code-block word wrap |
| **Z.ai** | `chat.z.ai`, `zchat.z.ai`, `www.zchat.z.ai` | No sidebar chat list sync (Chats tab hidden); local data isolated between `chat.z.ai` and `zchat.z.ai` |
| **ChatGLM** | `chatglm.cn` | No sidebar chat list sync (Chats tab hidden); supports share-page API export |
| **ima** | `ima.qq.com` | No sidebar chat list sync (Chats tab hidden); no native page theme sync |

## Privacy and local-first design

- **Stored on your device**: Settings, folders, tags, prompts, bookmarks, and reading history live in your browser's local storage (or your userscript manager's local storage).
- **No Ophel account or tracking**: Ophel has no login, no ads, and no in-extension analytics.
- **Minimal optional network access**: Ophel only talks to the network when you configure your own WebDAV server, when Site Packs checks its signed read-only update index (every 24 hours when auto-update is enabled), or if you choose to submit the optional uninstall survey. See [Privacy](/data/privacy) and [Permissions](/data/permissions).
